16 / バージョン付録0.1.0 から 0.1.56 までの全変更記録

本付録は、v0.1.0–v0.1.56 の正式版形式の番号を持つ 57 タグと、0.1.40 のプレビュー系列を扱います。2026 年 10 月 9 日に確認した公開リリース記録では、GitHub 上で現在参照できるのは、正式 Release 56 件、プレリリース 3 件の計 59 件です。v0.1.39 にはバージョンタグがありますが、現在、対応する公開 Release はありません。

最新の正式版 v0.1.56 は、北京時間の 2026 年 10 月 9 日 01:03:01に公開されました。元の UTC 時刻は 10 月 8 日 17:03:01 です。以下の表は、すべて北京時間の日付に統一しています。明示した v0.1.39 のタグ日付を除き、日付は Release の published_at に基づいており、コミット日を公開日の代わりにはしていません。

各版の変更を足し合わせたものが、現在の機能になるわけではありません。表は、各版が当時加えた変更を記載しています。エキスパートの統括機構は 0.1.44–0.1.48 で廃止され、以前のエキスパートの手法は Skill に変換できます。0.1.32 の独立した読み上げスイッチも 0.1.48 で削除されました。現在の動作は、0.1.56 の実装と明示された制約を基準に判断してください。

0.1.40 のプレビュー系列：番号があっても公開済みとは限らない

変更をさかのぼって調べるには

正式リリースの項目は対応する Release に、v0.1.39 はバージョンタグにリンクしています。変更の要約は、正式なリリースノートと隣接タグ間のコミットを突き合わせ、計画文書にしかない機能を提供済みとして記載しません。実装を調べる場合は、その版のタグまたはリリースコミットに固定し、変わり続ける main で過去の版を説明しないようにしてください。

リポジトリーの一部のリリース草稿には、ビルド前の HOLD や草稿の注記が残っています。当時の公開手順を知る資料にはなりますが、現在公開されているかどうかを単独で判断する根拠にはすべきではありません。公開 Release の状態と最終検証記録を併せて確認する必要があります。ここでいう「現在、公開 Release なし」は今回確認できた状態を表し、リリース文書によれば、v0.1.39 と beta.2 にはかつて未公開の Release 草稿がありましたが、現在は Release の一覧にありません。
