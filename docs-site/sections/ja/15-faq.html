15 / よくある質問Arslan を使い、理解するうえで混同しやすいこと

モデルの Web サイトで直接チャットする場合と、Arslan はどう違いますか？

Arslan はモデルに加え、ローカルファイル、ツール、タスク状態、記憶、承認、デスクトップ連携を提供します。モデルが判断と生成を担い、アプリがツール要求を制御された実行につなげ、結果を記録します。価値があるかどうかは、この一連の仕組みで具体的なタスクを完了できるかにかかっています。

一人で AI を使って開発しているプロジェクトですか？

はい。作者が独立して、AI の支援を受ける開発、いわゆる vibe coding により、Arslan の構築と改善を継続しています。製品にはオープンソースのフレームワーク、第三者のコンポーネント、外部モデルを使用しており、それぞれの出典とライセンスはプロジェクトの文書に記録されています。

すべての内容が自分の端末内に留まりますか？

主なデータ保存と実行の制御はローカルで行います。クラウドモデル、検索、リモート MCP などを利用すると、関連するリクエストが各サービスに送信されます。記憶には、クラウドでの使用許可と機密性に関する独立したルールもあります。ローカル優先は、全工程がオフラインであることを意味しません。

モデルを変更したり、ローカルモデルを接続したりできますか？

対応するプロバイダーや互換エンドポイントを設定できます。OpenAI 互換のローカルサービスも含まれます。エンドポイントに接続できても、確認できるのは通信が成立することだけです。ツール呼び出し、画像、推論の継続、コンテキスト長は、そのモデルとアダプターの経路が対応している必要があります。

初期の文書には多数のエキスパートが登場するのに、今は Arslan が一つだけなのはなぜですか？

製品の仕組みを統一してきたためです。0.1.44 でエキスパートの作成と割り当てを終了し、0.1.46 で旧来の自動進化ループを停止、0.1.48 で前段のルーターを削除しました。以前の手法は Skill に変換でき、過去のデータとの互換性も維持しています。制限付きの読み取り専用ワーカーは、独立した調査に引き続き使われます。

記憶、ナレッジベース、チャット履歴は同じものですか？

異なります。チャット履歴は会話を記録し、作業コンテキストはそこから最近の内容や要約を選びます。個人の記憶は、出典と権限を伴う好み、事実、ルールを保存します。知識検索は、取り込んだ資料から関連する部分を探します。三者では、保存、想起、削除の意味がそれぞれ異なります。

「経験の学習」はモデルを訓練したり、自動で権限を増やしたりしますか？

しません。現在の学習は、再利用できる手法を記録して後のタスクで呼び出すもので、基盤モデルの重みや実行の許可を変更しません。経験を取得、想起、適用できることは記録で確認されていますが、一般的な高速化や費用削減には、さらに比較実験が必要です。

すべてのコマンドはネット接続のないサンドボックスで実行されますか？

いいえ。標準の Python 計算サンドボックスはネットワークを拒否しますが、通常のターミナルのワークスペースサンドボックスは、一般にネットワークアクセスを維持し、独自のフォールバック動作を持ちます。ツールの権限、コマンドのポリシー、OS の権限、サンドボックスは別の層です。具体的な違いはセキュリティの章を参照してください。

チャットのウィンドウを閉じると、タスクはどうなりますか？

接続とタスクは別々に管理されます。アプリのサービスが動いていれば、バックグラウンドジョブは実行を続けられます。ウィンドウを閉じることは、必ずしもプロセスの終了を意味しません。サービスが終了したり Mac がスリープしたりすると、ローカル実行は継続できません。再起動後は記録から中断状況を確認し、対応する経路で明示的に再開します。

再開すると、以前の操作をすべて自動でやり直しますか？

いいえ。再開時には完了済みの手順と外部への影響を調べ、副作用が不明なら先に確認します。タスクの試行、操作の状態、チェックポイント、バージョンの制約は、古い結果による新しい状態の上書きを防ぐために役立ちます。ただし、すべての外部システムに対して厳密に一度だけの実行を保証することはできません。

Hands はどの Mac アプリでも操作できますか？

互換性は、アプリが公開する Accessibility の構造、OS の許可、Arslan の操作ルールに依存します。コントロールを読み取れることは、あらゆる業務操作を安全に完了できることを意味しません。機密性の高いボタンやキー操作には、より細かな確認が入り、一部のアプリやコントロールは未対応の場合があります。

Mac の電源が切れていても、iPhone が代わりにタスクを完了できますか？

Mac Bridge の経路では、実行を担うのは引き続き Mac です。Mac が利用できない間、メッセージは iCloud で待機します。v0.1.53 では Mac 側の Bridge がリリースされ、v0.1.54 ではそれを iPhone アプリ向けに整えましたが、それをもって iPhone クライアントの正式公開を判断することはできません。スマートフォンに受信済みと表示されても、タスクが完了したとは限りません。

テストがすべて通れば、どんな実タスクでも完了できますか？

テストが確認するのは、それぞれの条件の範囲だけです。ユニットテストは局所的なロジック、プロトコルテストは境界の整合性、インストール検証は配布物、実タスクの比較は特定のモデルとタスクでの成果を確認します。モデル、Web ページ、OS の権限、外部アプリによって結果は変わり得ます。

なぜバージョン番号がまだ 0.1.x なのですか？

プロジェクトは、v1 に至る前の継続的な改善段階にあります。50 を超える番号は、その改善の過程を表しています。成熟度は、具体的な機能、失敗への対処、テストの範囲、リリース状態を併せて判断すべきです。本書の完全なバージョン付録では、これらの違いを保持しています。
