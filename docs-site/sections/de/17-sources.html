Diese Dokumentation beschreibt die Implementierung einer festgelegten Version und gleicht öffentliche Veröffentlichungen, Git-Tags und -Historie, den Quellcode des Release-Commits, Architekturentscheidungen und öffentliche Abnahmeunterlagen miteinander ab. Frühere Entwürfe erklären die Entwicklung; Verhalten, das späterer Code ersetzt hat, ist als historisch gekennzeichnet. Die Angabe zur eigenständigen Entwicklung mit KI-Unterstützung stammt vom Autor.
