14 / 术语表从术语回到具体实现

术语用于区分不同机制。下表给出简明定义，并把每个概念放回 Arslan 的实现中；历史机制会明确标注。

AI 与上下文

术语通俗解释在 Arslan 里怎么用
LLM理解与生成语言的大模型来自用户配置的供应商；Arslan 负责应用与执行系统
Agent会根据结果决定下一步的执行过程调用模型、运行工具、看结果、继续或收尾
Orchestrator把不同能力安排到一起的协调者协调模型、上下文、工具、权限与任务状态
Tool calling模型用结构化方式请求一个工具工具名和 JSON 参数经过校验才执行
Native tool protocol使用供应商正式定义的工具消息格式保持 tool call ID、结果和推理延续正确对应
Trajectory模型与工具交互的结构化轨迹OpenAI 兼容采用 native history，其他 Provider 保留各自路径
Context window模型单次能看到的信息范围不能把所有历史、所有记忆和完整长输出无限塞入
Compaction把旧上下文压缩成有界摘要控制请求体，保留近期内容；不等于删除原始会话
RAG先找相关资料，再让模型回答从导入知识里检索片段，并带上来源
FTS5SQLite 的全文检索擅长找词面匹配，即使没有向量也能查资料
Embedding把文本意思转换为数字向量帮助找措辞不同但语义相近的内容
Cosine similarity比较向量方向是否相近语义检索的一种相似度计算方法
RRF把多种检索结果按名次合并融合 FTS 和向量排名，不直接混合不同单位的分数
Skill可复用的“怎么做”说明SKILL.md、可选脚本与参考；不是另一个模型
MCPAgent 与外部工具之间的标准接口通过 stdio 或 HTTP 接外部能力，授权仍需应用控制
BYOK用户自带模型 API 密钥由用户选供应商并承担对应模型调用费用
Prompt injection把网页或工具内容伪装成给 Agent 的新指令外部内容按数据处理，未经确认的外部影响经验通常进入提案；这不是彻底免疫证明
Learned practice从纠正或成功绕路中记下的方法“此机 AppleScript 不通，尝试 EventKit”；不修改模型权重
Shadow mode只记录判断，暂不让它改变实际行为判断层可记录审批建议，真实卡片仍等用户点
Held-out evaluation留出没用于改提示词的题目来考试早期专家演进的历史设计，不是当前每轮对话的固定步骤

软件架构、状态与可靠性

术语通俗解释在 Arslan 里怎么用
SPA在一个 Web 应用里切换页面与状态React 工作台由本地服务提供静态资源
Sidecar随主应用一起启动的辅助进程Tauri 旁边运行的 Python 本地后端
IPC同一电脑上进程之间的通信管道、Unix socket；不是所有模块都通过云通信
REST / HTTP一次请求获取或修改一个资源设置、历史、任务与文件管理接口
WebSocket保持双向连接持续推送信息回复流、工具状态、审批与进度事件
Async I/O等待 I/O 时让出事件循环，供其他任务推进Python asyncio、异步 API 与数据库访问；不等于 CPU 任务无限并行
Schema / Contract输入、输出和合法状态的明确约定Pydantic、工具参数与任务验收契约
State machine用有限状态描述一个流程走到哪queued、running、waiting_user、verifying、succeeded 等
Checkpoint记录走到哪、做过什么、还剩什么任务恢复用引用、证据和预算，不盲目重播未知副作用
Attempt任务的一次执行尝试恢复产生新尝试，旧异步结果不能覆盖新轮状态
Optimistic concurrency写入前确认数据还是自己刚才看到的版本row version 和 attempt ID 防止旧结果覆盖取消或更新
Idempotency重复请求不应造成意外重复操作消息／任务 ID 防重；外部未知效果还需要核对
ACK接收方说“这个包我收到了”不表示任务做成，也不表示审批已经生效
Single-flight上一轮没结束，就不重叠启动同一项定时任务避免一层层堆积重复执行
Backoff失败后逐渐拉长重试间隔限流／服务错误退避，尊重 Retry-After；认证错误不盲重试
WALSQLite 先写日志，改善读写共存本机数据持久化；仍有写并发边界
Migration把旧数据库结构安全升级到新结构显式版本 runner、升级前备份、拒绝未知 schema
Provenance一条信息从哪里来文档来源、记忆来源、真实运行轨迹
Observability出现问题时能看见发生了什么Run/Step、Activity、usage、错误与产物关联

操作系统、安全与交付

术语通俗解释在 Arslan 里怎么用
Sandbox / Seatbelt由操作系统限制进程可访问的资源计算沙箱和命令沙箱规则不同，网络与降级行为分别说明
Fail-closed保护层不可用就拒绝执行适用于默认 Python 沙箱和离线收尾路径；不能套用全部普通命令
Accessibility tree系统暴露的窗口、按钮、文本等结构Hands 读取和定位控件，不依赖截图像素识别
TCCmacOS 的隐私权限管理体系辅助功能、麦克风、Apple Events 等不是应用自己点个开关就获准
SSRF诱导服务访问不该访问的内部地址网页提取和外部 URL 需要校验目标、重定向与网络边界
AEAD同时保护内容秘密性和完整性的加密方式Bridge 使用 ChaCha20-Poly1305，篡改后验证失败
Key agreement / Signature前者协商加密材料，后者验证发送者身份X25519 与 Ed25519 职责不同，不要混说
Replay protection不让攻击者重复投递旧消息再次生效签名、收件人、序号滑窗、持久去重共同作用
CI / CD把构建、检查与分发流程自动化成功 CI 必须对应待发布 SHA，最后产物还要检查
Contract test验证边界两端遵守同一协议Python/Rust、Mac/iPhone 共享正例和负例向量
Mutation testing故意弄坏保护逻辑，看测试能否抓住用于证明特定断言有区分度，不是换个名字的普通单元测试
Code signing验证软件来源与产物未被修改App 与内嵌 helper 都需要正确签名
Notarization / StapleApple 检查发行包，再把票据附到包里与签名不同，还要用 Gatekeeper 验收结果
Fresh-install acceptance模拟没有开发环境、没有旧数据的新用户验证真正安装包的认证、WebSocket、资源与 helper

当前系统主要是本地分层单体加独立 helper。SQLite 与进程内异步调度适配个人桌面产品的安装和运行方式；相关术语都应在这一部署规模下理解。
