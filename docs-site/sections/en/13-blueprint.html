Arslan has three foundations: execution, ongoing work and memory. What is worth verifying next is whether these hold correct state, give reliable results and leave the user in control in more complex situations. Real-task results

A fixed task set should cover search completeness, citations matching conclusions, files that open, where system operations actually land, and whether a failure is wrapped up honestly. The existing comparison exposed gaps in research tasks; before widening the tool list, locating at which step "not found, not fully read, not verified, not delivered correctly" happens does more for the completion rate.

Recovery and consistency across devices

Network retries, duplicate messages, app restarts and user cancellation can happen at the same time. Further verification can centre on stable business IDs, final states that old messages cannot overwrite, behaviour after an approval is cancelled, and the checking path when a side effect is unknown. Crash injection and protocol negative cases can make clear which cases can be handled automatically and which must go back to the user.

Measurable gains from learning

A practice being remembered is only the start. Completion rate, call cost, time and wrong behaviour need comparing repeatedly, with and without the practice, on the same tasks and models. It also needs checking whether stale practices get corrected, whether external text can contaminate practices, and whether a deleted practice is still recalled.

The cost of platforms and extensions

Tauri provides a cross-platform host, but Seatbelt, Vision, Accessibility, Apple Events and CloudKit are all platform-specific. Moving to another desktop system means replacing and verifying these capabilities; a cross-platform compile is not the same as the product's features having moved. More external tools likewise mean more credentials, permissions and failure modes.

These directions are drawn from the current implementation and test results. Actual priorities and dates are whatever later release notes say.
