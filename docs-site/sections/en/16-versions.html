16 / Version appendixEvery change from 0.1.0 to 0.1.57

This appendix covers the 58 stable-format version tags v0.1.0–v0.1.57, plus the 0.1.40 preview branch. Going by the public release records checked on 9 October 2026, GitHub currently shows 57 releases and 3 prereleases, 60 in all. v0.1.39 has a version tag but currently no public release.

The latest release, v0.1.57, was published at 14:11:18 Beijing time on 9 October 2026 (06:11:18 UTC on 9 October). The table uses Beijing-time dates throughout. Apart from v0.1.39's tag date, which is marked, dates come from each release's published_at; commit dates are never used in place of publication dates.

Version changes are not a running total of today's capabilities. The table describes what changed in each version at the time. Expert orchestration was retired in 0.1.44–0.1.48, and old expert methods can be converted into Skills; 0.1.32's separate read-aloud switch was also removed in 0.1.48. For current behaviour, go by 0.1.57's implementation and its stated limits.

How to trace a change

Released entries link to their release; v0.1.39 links to its version tag. Summaries combine the official release notes with the commits between neighbouring tags, and never describe something that exists only in a planning document as delivered. To check a specific implementation, pin to that version's tag or release commit, rather than reading the past through the ever-changing main branch.

Some release documents in the repository still carry pre-build HOLD or draft notes. They show how a release went at the time, but should not be used alone to judge whether something is publicly released; check the public release status and the final verification record together. "No public release now" here describes what is visible at the time of checking; the release documents show that v0.1.39 and beta.2 once had unpublished release drafts, which are no longer in the release list.
