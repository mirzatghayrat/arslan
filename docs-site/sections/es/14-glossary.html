14 / GlosarioDe los términos a la implementación concreta

Los términos distinguen mecanismos diferentes. Las tablas ofrecen definiciones breves y sitúan cada concepto en la implementación de Arslan. Los mecanismos históricos se señalan expresamente.

IA y contexto

TérminoExplicación sencillaUso en Arslan
LLMModelo de gran tamaño que comprende y genera lenguajeProcede del proveedor configurado por el usuario; Arslan se ocupa de la aplicación y del sistema de ejecución
AgentProceso que decide el siguiente paso según los resultadosInvoca al modelo, ejecuta herramientas, observa resultados y continúa o cierra
OrchestratorCoordinador que organiza distintas capacidadesCoordina modelos, contexto, herramientas, permisos y estados de tareas
Tool callingPetición estructurada del modelo para usar una herramientaEl nombre y los parámetros JSON se validan antes de ejecutar
Native tool protocolUso del formato de mensajes de herramientas definido oficialmente por el proveedorMantiene la correspondencia entre tool call ID, resultados y continuidad del razonamiento
TrajectoryTraza estructurada de interacciones entre modelo y herramientasLa ruta compatible con OpenAI utiliza native history; los demás Provider conservan sus propias rutas
Context windowInformación que el modelo puede ver en una sola peticiónNo permite incluir indefinidamente todo el historial, toda la memoria y todas las salidas extensas
CompactionCompresión del contexto antiguo en un resumen acotadoLimita el tamaño de las peticiones y conserva el contenido reciente; no elimina la conversación original
RAGBuscar información pertinente antes de pedir una respuesta al modeloRecupera fragmentos del conocimiento importado junto con sus fuentes
FTS5Búsqueda de texto completo de SQLiteEncuentra coincidencias léxicas y permite buscar documentación aunque no existan vectores
EmbeddingRepresentación del significado de un texto mediante un vector numéricoAyuda a encontrar contenido con distinta redacción y significado similar
Cosine similarityComparación de la proximidad entre direcciones de vectoresUna medida de similitud para búsqueda semántica
RRFFusión de resultados de distintas búsquedas según su posiciónCombina las clasificaciones FTS y vectoriales sin mezclar directamente puntuaciones de diferentes escalas
SkillInstrucciones reutilizables sobre cómo realizar un trabajoSKILL.md, scripts opcionales y referencias; no es otro modelo
MCPInterfaz estándar entre agentes y herramientas externasConecta capacidades externas por stdio o HTTP; la aplicación sigue controlando la autorización
BYOKEl usuario aporta su propia clave API de modeloElige el proveedor y asume el coste de sus llamadas al modelo
Prompt injectionDisfrazar contenido web o de herramientas como nuevas instrucciones para el agenteEl contenido externo se trata como datos; las prácticas influidas por él y no confirmadas suelen convertirse en propuestas. No demuestra inmunidad total
Learned practiceMétodos recordados a partir de correcciones o alternativas que funcionaron«AppleScript no funciona en este equipo; probar EventKit»; no modifica los pesos del modelo
Shadow modeRegistrar una decisión sin dejar que cambie todavía el comportamientoLa capa de juicio puede registrar sugerencias de aprobación; la tarjeta real sigue esperando un clic del usuario
Held-out evaluationReservar preguntas no utilizadas para modificar las instrucciones y emplearlas para evaluarDiseño histórico de evolución de expertos, no un paso fijo de cada conversación actual

Arquitectura, estado y fiabilidad

TérminoExplicación sencillaUso en Arslan
SPACambiar páginas y estados dentro de una aplicación webEl servicio local distribuye los recursos estáticos del entorno React
SidecarProceso auxiliar que arranca junto con la aplicación principalBackend Python local que se ejecuta junto a Tauri
IPCComunicación entre procesos del mismo equipoCanales y sockets Unix; no todos los módulos se comunican por la nube
REST / HTTPObtener o modificar un recurso mediante una peticiónInterfaces de ajustes, historial, tareas y gestión de archivos
WebSocketConexión bidireccional persistente para enviar informaciónRespuestas en streaming, estados de herramientas, aprobaciones y eventos de progreso
Async I/OCeder el bucle de eventos mientras se espera E/S para que avancen otras tareasPython asyncio, API y acceso a datos asíncronos; no implica paralelismo ilimitado en trabajo de CPU
Schema / ContractAcuerdo explícito sobre entradas, salidas y estados válidosPydantic, parámetros de herramientas y contratos de aceptación de tareas
State machineRepresentar el avance de un proceso mediante un conjunto finito de estadosqueued, running, waiting_user, verifying, succeeded y otros
CheckpointRegistrar el avance, lo realizado y lo pendienteLa recuperación utiliza referencias, evidencias y presupuesto; no repite a ciegas acciones de efecto desconocido
AttemptUn intento de ejecución de una tareaReanudar crea un intento nuevo; los resultados asíncronos antiguos no pueden sobrescribir el estado actual
Optimistic concurrencyComprobar antes de escribir que los datos siguen en la versión leídarow version y attempt ID impiden que resultados antiguos sobrescriban cancelaciones o actualizaciones
IdempotencyUna petición repetida no debe causar una repetición accidental de la operaciónLos ID de mensajes y tareas evitan duplicados; los efectos externos desconocidos requieren comprobación
ACKEl receptor confirma que recibió el paqueteNo significa que la tarea esté completada ni que la aprobación ya haya surtido efecto
Single-flightNo iniciar otra ejecución de la misma tarea si la anterior no ha terminadoEvita la acumulación de ejecuciones repetidas de tareas programadas
BackoffAumentar progresivamente la espera entre reintentos tras un falloEspera progresiva ante límites de peticiones o errores de servicio, respetando Retry-After; no reintenta a ciegas errores de autenticación
WALSQLite escribe primero en un registro para facilitar lecturas y escrituras concurrentesPersistencia local, todavía con límites de concurrencia de escritura
MigrationActualizar de forma segura la estructura de una base de datos antiguaEjecutor explícito con versiones, copia previa y rechazo de esquemas desconocidos
ProvenanceDe dónde procede una informaciónFuentes de documentos y memoria y trazas reales de ejecución
ObservabilityPoder ver lo sucedido cuando aparece un problemaRun/Step, Activity, usage y asociación de errores con entregables

Sistema operativo, seguridad y distribución

TérminoExplicación sencillaUso en Arslan
Sandbox / SeatbeltRestricción de recursos accesibles a un proceso impuesta por el sistema operativoLos sandboxes de cálculo y comandos tienen reglas distintas; red y comportamiento degradado se describen por separado
Fail-closedDenegar la ejecución si la protección no está disponibleSe aplica al sandbox Python predeterminado y al cierre sin conexión; no a todos los comandos ordinarios
Accessibility treeEstructura de ventanas, botones, texto y otros elementos expuesta por el sistemaHands lee y localiza controles sin depender del reconocimiento de píxeles de capturas
TCCSistema de gestión de permisos de privacidad de macOSLa aplicación no obtiene permisos de accesibilidad, micrófono o Apple Events simplemente activando un interruptor propio
SSRFInducir a un servicio a acceder a direcciones internas que no debería consultarLa extracción web y las URL externas requieren validar destinos, redirecciones y límites de red
AEADCifrado que protege simultáneamente confidencialidad e integridadBridge utiliza ChaCha20-Poly1305; una manipulación hace fallar la validación
Key agreement / SignatureEl primero acuerda material de cifrado; la segunda verifica la identidad del emisorX25519 y Ed25519 tienen funciones diferentes y no deben confundirse
Replay protectionEvitar que un atacante vuelva a entregar mensajes antiguos para repetir sus efectosFirma, destinatario, ventana de secuencias y deduplicación persistente actúan conjuntamente
CI / CDAutomatizar compilación, comprobaciones y distribuciónLa CI satisfactoria debe corresponder al SHA que se publica; los paquetes finales también se comprueban
Contract testVerificar que ambos extremos respetan el mismo protocoloPython/Rust y Mac/iPhone comparten vectores de casos válidos y negativos
Mutation testingDañar intencionadamente la protección para comprobar si las pruebas lo detectanDemuestra que ciertas aserciones distinguen un comportamiento incorrecto; no es otro nombre para una prueba unitaria corriente
Code signingVerificar la procedencia del software y que el paquete no se haya modificadoLa aplicación y sus helpers deben estar firmados correctamente
Notarization / StapleApple examina el paquete y después se le adjunta el ticketEs distinto de la firma; además hay que verificar la aceptación con Gatekeeper
Fresh-install acceptanceSimular un usuario nuevo sin entorno de desarrollo ni datos anterioresComprueba autenticación, WebSocket, recursos y helpers del paquete real

El sistema actual es principalmente un monolito local organizado en capas, con helpers independientes. SQLite y la planificación asíncrona dentro del proceso se adaptan a la instalación y ejecución de un producto de escritorio personal. Los términos deben entenderse dentro de esa escala de despliegue.
