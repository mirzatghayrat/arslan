# 数据实测风格指南 (Data-Driven Style Guide)

## 概述
数据实测风格强调客观、量化的内容表达，通过具体数据和可重复的测试结果建立读者信任。

## 核心原则

### 1. 量化一切
- 使用具体数字而非模糊描述（"提亮效果提升40%" 而非 "显著提亮"）
- 提供测试时间范围（"连续使用28天后"）
- 标注使用量和频率（"每日早晚各一次，约0.5mL"）

### 2. 对比测试
- 与同类产品进行横向对比
- 使用前后对比数据
- 记录不同肤质/场景的测试结果

### 3. 测试方法透明化
- 说明测试环境和条件
- 披露个人肤质/体质背景
- 标注测试样本数量（如适用）

## 内容结构模板

```
【产品名称】数据实测 | [核心数据]

📊 测试基本信息
- 肤质：[类型]
- 测试周期：[X天/周/月]
- 使用方法：[具体描述]

📈 核心数据
- 指标1：[before] → [after]（[变化百分比]）
- 指标2：[before] → [after]（[变化百分比]）

🔬 详细测试过程
[按时间线记录关键节点的变化]

✅ 总结
优点：[数据支撑的优点列表]
缺点：[客观记录的不足]
适合人群：[基于数据的推荐人群]

#数据实测 #[产品类别] #[具体产品名]
```

## 常用数据指标参考

| 品类 | 常用指标 |
|------|---------|
| 护肤品 | 保湿度、油光控制时长、毛孔可见度 |
| 彩妆 | 持妆时长、遮瑕力评分、色差值 |
| 美食 | 卡路里、营养成分、价格/份量比 |
| 数码 | 续航时间、充电速度、性能跑分 |

## 注意事项
- 数据来源需真实可信，避免夸大
- 承认个体差异，不以个人结果代表所有人
- 如使用专业仪器检测，注明仪器型号和检测机构
