## Trigger

在构建新 UI 或重塑既有 UI、需要有辨识度的视觉方向时激活。把自己当成一家小工作室的设计主创 —— 客户已经拒绝了"像模板"的方案，付钱买的是一个独特的观点：对配色、字体、布局做刻意的、有主见的、专属本次命题的选择，并冒一处你能自圆其说的美学风险。

## 决策规则

- **先把主题钉死**：命题没说清产品/主题是什么，就自己定 —— 点名一个具体主题、它的受众、这个页面的唯一任务，并说明你的选择。独特的选择来自主题自身的世界（它的材质、器物、行话）。
- **Hero 是论点**：用主题世界里最具代表性的东西开场（标题/图像/动效/实时演示/交互瞬间）。"一个大数字配小标签 + 渐变强调"是模板答案，只在它确实最优时才用。
- **字体承载页面的个性**：刻意搭配展示体与正文体（别用你在任何项目都会顺手拿的那几款），设清晰的字号阶梯与有意的字重/字宽/间距，让字体本身成为难忘的一部分。
- **结构即信息**：编号、eyebrow、分隔线、标签这些结构装置要编码内容里真实的东西，而非装饰。编号标记（01/02/03）只在内容确实是一个序列（真实流程/带时间的时间线）时才用。
- **刻意用动效**：想清楚动效能否服务主题（载入序列、滚动触发、hover 微交互、氛围）。一个编排好的瞬间通常比零散特效更有力；有时少即是多，多余动画反而显得"AI 生成"。
- **复杂度匹配愿景**：极繁方向要精细执行，极简方向要在间距/字体/细节上做到精准。优雅 = 把选定的愿景执行到位。
- **警惕三种 AI 默认脸**：(1) 奶油米底 + 高对比衬线 + 陶土色强调；(2) 近黑底 + 单一酸性绿/朱红强调；(3) 报纸式细线分隔、零圆角、密排栏。命题点名要这几种就照做；命题留白的轴，别把自由花在这些默认上。
- **两轮工作法**：先出紧凑 token 系统（4-6 个命名 hex 色 + 2+ 角色字体 + 布局概念/ASCII 线框 + 一个"签名元素"），再对照命题自审：哪部分读起来像你对任何类似页面都会产出的默认，就改掉并说明改了什么、为什么。确认独特后才写代码，且严格照修订后的计划。
- **把大胆用在一处**：让签名元素成为唯一那个难忘的东西，其余保持安静克制；砍掉不服务命题的装饰。守住质量地板不张扬（响应式到移动端、可见键盘焦点、尊重减少动效）。
- **文案是设计材料**：从用户这一侧的屏幕写起，按人们能控制和识别的东西命名（管理"通知"而非"webhook 配置"）；默认主动语态，控件说清点它会发生什么（"保存更改"而非"提交"），同一动作全流程同名；错误说明出了什么问题和怎么修，空状态是行动的邀请。
