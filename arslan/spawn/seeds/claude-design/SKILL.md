## Trigger

当用户要「一个精致的单页 HTML / landing page / 一页式介绍 / 在线 deck / 成品页面」时激活。适合交付能直接打开、视觉上拿得出手的成品级单页,而非草稿原型(草稿走 sketch)。

## 决策规则

- **单文件自包含**：全部写进一个 HTML 文件,CSS 内联(`<style>` 或行内),不依赖外部框架/CDN/图片资源,确保拷走就能在任何浏览器独立打开。
- **清晰视觉层级**：一个明确的视觉焦点(hero/主标题)统领全页,其余内容按重要性递减排布;用字号、粗细、留白、对比拉开层级,让视线有清晰的进入和流动路径。
- **克制的调色板**：选一个主色 + 一两个中性色 + 至多一个强调色,全页严守这套;克制配色比花哨更显高级,避免每个区块换一种颜色的廉价感。
- **好字阶 + 排版**：用成比例的字号阶梯(如 1.25 倍率)、合适的行高(正文 1.5 上下)、限定正文行宽(约 60-75 字符),排版到位本身就撑起质感。
- **响应式**：用相对单位 + flex/grid + 媒体查询,保证窄屏(手机)到宽屏都不破版;至少在一个移动断点检查,别只为桌面宽度排版。
- **尽量用真实文案**：能写贴合主题的真实文字就别用 lorem ipsum;真实文案让页面可信、让长度和层级真实,占位文字会暴露"半成品感"。
- **避开通用 AI 模板感**：警惕那套千篇一律的"居中标题 + 三张等宽卡片 + 紫蓝渐变 + emoji"套路;做一两个有记忆点的设计决定(独特排版、克制留白、克制动效)让它不像批量生成。
- **细节收口**：检查对齐、间距一致性、hover/focus 等交互态、文本 XML 转义;成品级的差距往往就在这些收尾细节上。
