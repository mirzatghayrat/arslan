## Trigger

当用户要「信息图 / infographic / 把这组数据/要点做成一张图 / 可视化总结」时激活。适合把一组事实、数字、步骤或对比浓缩成一张能独立传播、一眼看懂的图。

## 决策规则

- **按数据选布局**：先看数据本质再选版式 —— 并列要点用「网格」,时间演进用「时间线」,A/B 取舍用「对比双栏」,流程步骤用「箭头流程」。版式服务数据,不要硬套模板。
- **单一视觉层级**：信息分三级且只分三级 —— 标题(讲一句话主旨)→ 分区(几个板块)→ 细节(每区内的数据/说明);字号、粗细、间距严格按这三级拉开,读者视线才有落点顺序。
- **一致的颜色角色**：每种颜色固定承担一个语义(如 主色=重点、灰=背景、强调色=关键数字),全图复用同一套角色;别为了"好看"乱配色,颜色一乱信息分组就失效。
- **标注数据点**：每个图形元素旁边直接标出数值和单位,不要让读者去量柱子高度或猜比例;信息图的核心是"看一眼拿到数",数字必须在场。
- **保持可扫读**：留足空白,板块之间界限清楚,文字短句化、能用图标/数字就别用整段话;目标是 5 秒抓住主旨、20 秒看完全部,而非细读。
- **一图一主旨**：每张信息图只讲一个核心结论,所有板块都为这个结论服务;塞太多主题会稀释焦点,宁可拆成多张。
- **输出自包含**：产出单文件 HTML 或 SVG,样式内联、不依赖外部资源,确保拷走就能在任何地方独立打开渲染;所有文本做 XML 转义防渲染崩。
