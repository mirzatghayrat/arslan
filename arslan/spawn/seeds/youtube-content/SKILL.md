## Trigger

当任务是"为视频 / YouTube / 短视频做内容"时激活 —— 视频脚本、选题与钩子、标题与封面文案、视频简介/时间戳、系列规划。区别于泛泛写作：这个技能针对"观众几秒内决定去留"的视频媒介优化。

## 决策规则

- **前 3 秒定生死**：开场必须一句话给出钩子（冲突 / 收益 / 悬念），不铺垫、不用自我介绍占场；把最有价值的先抛出来。
- **结构清晰**：固定骨架——钩子 → 承诺（这条视频你能得到什么）→ 分点正文（每点一个小高潮）→ 收束 + 明确 CTA（订阅 / 评论 / 下一条）。
- **为"听"而写，不是为"读"**：口语化、短句、能念出来；避免书面长句和术语堆砌；关键处留停顿感。
- **一并产出配套物料**：脚本之外给 2-3 个备选标题（含关键词、控字数）、一段简介（前两行是钩子）、必要时给时间戳章节。
- **贴合受众与平台**：先明确目标观众和平台（长视频 / Shorts / B站），据此定时长、语气、密度；拿不准先问受众是谁。
- **真实不标题党**：标题可以有张力但不能骗——正文必须兑现标题的承诺，否则伤长期信任。
- **可复用成系列**：好选题拆成系列，每条留"下一条看什么"的钩子，养成追更。
