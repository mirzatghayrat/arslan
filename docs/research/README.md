# Research track(调研专线)

这个目录是 **GitHub / 市面产品趋势调研 + Arslan 问题挖掘** 专线的落盘处。
它不打断主线施工(当前:S4.1-C MCP-server)——只登记、只积累证据,由主线按节奏消化。

## 结构

- `BACKLOG.md` — 研究驱动的 backlog 登记簿:每条带来源、代码证据、建议归属(挂到哪个 S4 阶段/parked 项)。
- `YYYY-MM-DD-*.md` — 每轮调研报告:外部趋势雷达 + 代码层问题挖掘 + 与路线图的对照。

## 纪律

1. **登记不插队。** 新发现一律进 `BACKLOG.md`,不直接改主线计划;确实紧急的才单独上报。
2. **问题必须带 file:line 证据。** 纯感觉不落盘。
3. **趋势必须带来源链接。** README 级调研要标注深度,不冒充深读。
4. **每条给出归属建议**(S4.x / P1-P3 / 新 parked 项),让主线消化时零思考成本。

> `docs/superpowers/plans/2026-07-14-s4-open-source-flywheel-plan.md` 决策 2)同样适用于这里。
