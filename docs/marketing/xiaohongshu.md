# 小红书内容包 · Arslan

按 `marketing-xiaohongshu-operator` 的爆款框架写：标题 18–20 字（关键词 + 情绪词）、
封面竖版 3:4 大字报、正文四步（痛点共鸣 → 自然引入 → 具体体验 → 适度降低期望）、
标签 2–3 热门 + 3–5 长尾。

所有事实取自 `video/src/facts.ts`，每条在仓库里有出处。方法论里那条
「内容必须基于真实体验，拒绝虚构与过度修饰」在这里不是合规条款而是主线——
产品本身的卖点就是它不替你吹牛。

---

## 先说三个不好听的

**1. 视频必须是竖版。** 现有的片子全是 16:9。小红书信息流里 16:9 会被压成一条，
首帧是全部胜负手，压小等于放弃。已经出了 3:4 版本：`npm run f12` →
`F12-Glass15-RED`（1080×1440，15 秒）。**不要用横版裁剪**——机器会被切掉一半。

**2. 受众天花板很低，要认。** macOS + Apple Silicon、pre-v1、开源开发者工具。
小红书上真正会下载的人很少。所以内容目标不该是「转化下载」，而是
**「AE 做出了一个 AI 产品」这个人设的沉淀** —— 这个在小红书是能跑的，
产品是证据不是主角。把 KPI 定成互动率和主页关注，别定成 DMG 下载量。

**3. 别隐藏 pre-v1 和只支持 macOS。** 方法论里「适度降低期望强化真实感」在这里
是刚需：写清楚了，来的人预期正确；写不清楚，评论区第一条就是「Windows 呢」，
而且是你自己招来的。

## 六版文案

### V1 · 身份反差（主推）

> **标题**　我是做销售的，我把自己的AI做出来了
>
> **封面**（大字报，深色底 + 琥珀色字）
> 主字：`销售出身` / `我做了个AI` ｜ 角标：`没写过一行代码 · 全程vibe coding`
>
> **配片**：`F12-Glass15-RED`（15秒竖版）

```
去年这个时候我还在跟客户解释「AI能帮你做什么」。

说实话我自己都心虚——我讲得出概念，但我没真的用AI干成过一件复杂的事。
做销售最怕这个：你在卖一个你自己没吃透的东西。

后来我干脆自己上手做。不是学编程，是一句一句跟AI描述我要什么，
它写，我看，不对就再说一遍。就这样磨出了一个能在我自己电脑上跑的东西。

它叫 Arslan。你只跟一个主 agent 说话，它把活分给你自己养出来的分身。
不是固定给你几个角色，是你要几个养几个，每个配什么工具、什么技能包都你定。

做完最大的收获其实不是产品，是我终于能站在客户面前说
「这个事我自己做过，坑在哪我知道」。

⚠️ 目前只支持 macOS（Apple Silicon），还在 pre-v1，开源。
真不是给所有人用的，是给愿意折腾的人用的。
```

**标签**：`#AI工具` `#效率工具` ｜ `#销售人的自我修养` `#vibecoding` `#独立开发` `#转行` `#Mac软件`

### V3 · AI说谎（最有记忆点）

> **标题**　AI跟我说它做完了，其实它啥也没干
>
> **封面**（对比图，上下分栏）
> 上：`「已经交给XX处理了，稍等」` ｜ 下：`实际派单数：0`
>
> **配片**：`F12-Glass15-RED`

```
用过AI agent的应该都被这么骗过：

它特别自信地跟你说「我已经把这个交给某某模块了，正在生成，稍等一下」。
你等了半天，什么都没有。它根本没派过任何任务。

这个事在我自己做的东西上也发生过。我把它记下来了，
然后写了一段拦截逻辑——不是再叫一次模型去判断，是确定性的检查：
你说你派单了，那我就去查派单记录，对不上就不许你这么说。

最多重新组织一次语言，还骗就换成老实模板。

这大概是整个项目里我最满意的一部分。
它做不到的事，它不能跟你说它做到了。
```

> **封面**：Automation 页截图 + 大字 `默认全关`

```
做AI工具最容易出的事故是账单。

建议你先去你的模型服务商后台设个硬性消费上限。

还有记忆：它想删或者想改的东西，会先进收件箱等你确认，不会自己动手。

自己给自己写警告的产品不多，但我觉得这个比多一个功能重要。
```

```
聊天框的问题是：每次都从零开始。
```

## 发布节奏

方法论的三阶段用在个人号上要缩水——你没有 KOL 预算，铺的是自己的内容密度。

| 周 | 发什么 | 目的 |
| --- | --- | --- |
| 1–2 | V1、V6 | 立人设。先让人记住「销售做产品」这件事 |
| 3–4 | V3、V4 | 立观点。这两条最有记忆点，也最可能被转 |
| 5–6 | V2、V5 | 立产品。这时候再讲功能，前面的人设已经撑住了 |
| 长尾 | 评论区回复、把高赞评论做成新笔记 | 方法论里的「素人内容铺设」，你只能自己当素人 |

一周 2 条，别更密。个人号密度上去质量掉下来，反而压推荐。

## 合规清单

- **违禁词**：不写「最」「第一」「绝对」「顶级」「永久」「独家」「包」「秒杀」。
  上面六版已经避开了。
- **外链**：正文不放 GitHub 链接，会限流。放主页简介，或者评论区置顶「链接在主页」。
- **真实性**：所有功能描述都能在软件里点出来，截图是真截图。
  这条方法论写了「拒绝虚构与过度修饰」，我们的片子里连界面都是真截图不是画的。
- **不夸疗效**：不写「效率翻倍」「帮你赚钱」这类量化承诺，我们没测过。

## 评论区预埋

必然会被问的，提前想好答案：

- 「Windows 有吗」→ 目前没有，macOS 优先，这个在正文里已经说了
- 「收费吗」→ 开源，Apache-2.0，自己带模型 key
- 「小白能用吗」→ 老实说：现在还不能，pre-v1，适合愿意折腾的
- 「怎么做的 / 用什么做的」→ 这条最值钱，可以直接做成 V6 的续集
