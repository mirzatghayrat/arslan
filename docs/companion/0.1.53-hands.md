# 0.1.53 — Hands: Arslan uses your Mac apps (draft)

Design: `docs/specs/2026-10-03-0153-hands-agent-desktop.md` (§7 lists what measurement changed). agent-desktop 0.9.4
(Apache-2.0) is built from our fork `mirzatghayrat/agent-desktop` at the commit pinned in
`packaging/hands/agent-desktop.pin`.

## What was built

| Area | Files | What it does |
| --- | --- | --- |
| Arslan Hands (helper app) | `desktop/hands/`, `packaging/hands/` | A small app inside Arslan that alone holds the macOS Accessibility permission (Arslan.app never does: a permission Arslan held would reach every command it runs). The first time it is used, macOS asks you to allow "Arslan Hands". It reads apps through their accessibility tree — never screenshots — and acts in the background without taking your mouse, keyboard or focus. Only Arslan's own signed backend can talk to it. |
| Tools | `server/registry/hands_tools.py` | `desktop_apps`, `desktop_look` (asked once per app in a conversation), and, inside background work only, `desktop_click / type / select / scroll / press` (asked once per app per piece of work). A button that deletes, sends, pays, buys, transfers or submits — by its real label — asks every time. |
| Never | `desktop/hands/policy.json` | Never typed into: password fields. Never touched: Keychain Access, password managers, System Settings, macOS security prompts, Notification Center, Arslan itself. Web browsers are only read (Arslan's own browser acts on web pages); terminals and code editors are only clicked and scrolled. No clipboard, no screenshots, no debugging ports. Settings → Desktop shows the list; you can add apps. |
| Seen and stopped | island, menu bar, Activity | A labelled cursor while Arslan acts; the island shows the step and a Stop button; the menu bar has "Stop Arslan's hands"; Activity lists the last 7 days of Hands actions (typed text recorded as a length only). |
| Command sandbox | `server/services/command_sandbox.py` | Protected folders are now closed to socket connections too (they were not; measured), and Hands' folder is protected. |

## Measured on a real Mac

17 of the release smoke's checks passed (`scripts/hands_smoke.py`): looking, typing, clicking with the effect observed,
the password refusal, the never-list, "Delete" asking every time, Stop within 1 s (0.04 s), a sandboxed command
unable to reach Hands, agent-desktop holding no permission when run on its own, and the peer check (signed backend
accepted, impostor and unsigned program refused).

## Known gaps

- Hands sees only windows on the current desktop (Space); apps on another Space or behind a full-screen app are "not
  open".
- Large apps (Notes) can time out on a busy Mac; reads are retried once.
- The Notes and Finder acceptance tasks still need a run on a plain desktop.
