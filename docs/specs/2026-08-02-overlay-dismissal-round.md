## 0. 为什么不能照搬 A 组

A 组（锚定下拉）的规则是无脑的：**能关就关**。丢一个打开的下拉，代价是零。

B/C/D 不是。这里的元素**有的握着用户还没保存的东西**，有的**是一个等待裁决的提案**。
把 A 组的规则搬过来，等于给"手滑点了下空白"配上"你刚写的东西没了"。

⇒ **本轮的规则必须按「关闭的代价」分类，不是按「元素类型」分类。**

## 2. 提案的分类规则

| 类 | 判据 | 外部点击 | Escape |
|---|---|---|---|
| **只读查看器** | 关掉不丢任何东西 | ✅ 关 | ✅ 关 |
| **编辑器 / 表单** | 有用户输入 | ❌ **不关** | ✅ 关，但**脏了要确认** |
| **提案卡** | 关闭 = 谢绝 | ❌ 不关（手滑=误拒） | ✅ 关（= 显式谢绝，与既有 `noteUserSend` 隐式谢绝同族） |
| **首启向导** | 关掉 = 跳过配置 | ❌ 不关 | ❌ 不关（只走它自己的按钮） |

**共用既有原语**：`useDismissable(open, onClose)`（A 组已建）。
本轮加一个 `useDismissable(open, onClose, { outsideClick: false })` 开关，
**不新建第二套机制**。

## 3. 拍板项

① **编辑器脏状态下按 Escape 怎么办？**
  A（推荐）：**脏了就先确认**（"放弃未保存的改动？"），干净直接关。
  B：一律直接关（简单，但会毁掉输入）。
  C：一律不关（安全，但 Escape 在编辑器里变成死键，与其他浮层不一致）。

② **提案卡按 Escape = 谢绝，要不要留痕？**
  A（推荐）：与既有隐式谢绝一致，**静默关闭**，不写事件。
  B：记一条 `ConversationEvent`（可审计，但会给时间线塞噪声）。

③ **SpawnStudio 现有的"点外部关闭"要不要摘掉？**
  A（推荐）：**摘掉**——它是本轮唯一一个"编辑器 + 外部点击"的组合，即今天就能丢内容。
  B：保留（用户可能已形成肌肉记忆）。
  🔴 我的立场：A。这条不是新增限制，是**修一个现存缺陷**；且 ① 选 A 后 Escape 会给出一条安全的出路。

## 4. 验收（写死，实现轮照抄）

- **每一类各一条测试**，且断言要能区分类别：只读的**必须**能被外部点击关掉、
  编辑器的**必须不能**——只断言"能关"对本轮无区分力，因为本轮一半的要求是"不能关"。
- **脏状态判定要有测试**：干净的编辑器 Escape 直接关；脏的弹确认。
  mutation：把脏判定写死成 `false` 必红。
- **类守卫扩表**：A 组的 `floating-class-guard` 增加 B/C/D 条目，
  每条记「该不该外部点击关」及**理由**，与 A 组同格式。
- 🔴 **一条否定式**：断言 FirstRunWizard **不会**被外部点击或 Escape 关掉。
  这是唯一一个"关不掉是特性"的，没有它就会被后来者"顺手修好"。
