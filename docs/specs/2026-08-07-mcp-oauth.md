## 0. 前置核实(2026-08-07 亲核 `5f2b083b`,带 FILE:LINE)

### 0.1 客户端不在 `mcp_service.py` —— 唯一的 SDK 触点是一个函数

`server/services/mcp_service.py` 是 CRUD + health(`:41 add_server`、`:76 list_servers`、
`:150 check_health`)。**唯一的 SDK / 传输触点**是
`server/mcp/session.py:26-57 _open_session`,支持**恰好两种传输**:
```python
if transport == "http":
    streams = await stack.enter_async_context(
        streamablehttp_client(server["url"], headers=server.get("env") or {})   # :37-39
    )
else:  # stdio
    params = StdioServerParameters(command=…, args=…, env={**os.environ, **additions, **server_env})  # :50-53
```
由 `mcp_service.py:43` 校验:`if transport not in ("stdio", "http"): raise ValueError`。
**无 SSE、无 websocket。**

### 0.2 「OAuth 缺」对,「auth 缺」错 —— 两条静态凭据路今天都能用

- **stdio**:解密后的 env 变成子进程环境(`session.py:52`)。
  `server/mcp/catalog.py` 里的 `BRAVE_API_KEY` / `GITHUB_PERSONAL_ACCESS_TOKEN` 就这么走。
- **http**:`session.py:38` 把**同一个 env dict 原样当 HTTP headers 传**。
  ⇒ **手贴一个 bearer 今天就能用**,而且有测试钉住
  (`tests/server/test_mcp_http_transport.py:43-48`)。
  前端明说了这个意图:`web/src/components/McpServers.tsx:92`
  `// env doubles as HTTP headers`,`:439` transport=http 时标签渲染成 "Headers"。

⇒ **缺的是交互式授权 / token 刷新 / 401 挑战处理**,不是「认证」。

🔴 **今天没有任何东西看 HTTP 状态码**:401 会变成
`server/mcp/discovery.py:80` 的 `srv.last_error = str(exc)[:500]`,**零 auth 分类**。
(⚠️ 顺带:spec ⓪ §2.3 实测过 `str(InvalidToken())` **是空串** ——
同一条 `str(exc)[:500]` 上报路径在解密失败时会写进一个**空的** `last_error`。)

### 0.3 🟢 「要从零实现 OAuth」是错的 —— SDK 自带,而且是对的那一套

本轮用项目 venv **实测**(不是查文档):
```
mcp/client/auth/__init__.py   docstring: "OAuth2 Authentication implementation for HTTPX.
                                          Implements authorization code flow with PKCE
                                          and automatic token refresh."
exports: OAuthClientProvider, OAuthFlowError, OAuthRegistrationError,
         OAuthTokenError, PKCEParameters, TokenStorage
```
而 `streamablehttp_client` 的签名(实测打印)最后一个参数是:
```
auth: httpx.Auth | None = None
```
`OAuthClientProvider` **就是一个 `httpx.Auth`**。
而 `session.py:37-39` **传了 `headers=`、从来没传 `auth=`**。

⇒ **那个没用的 kwarg 就是全部接入面。**
工作量 = 一个走我们 crypto 的 `TokenStorage` 实现 + 一个 redirect/callback handler,
**不是实现协议**。

🔴 **设备码 SDK 里没有**:grep
`device_code|device_authorization|urn:ietf:params:oauth:grant-type:device_code`
在 `mcp/client/auth/` **零命中**;它实现的是 authorization-code + PKCE
(另有 `extensions/client_credentials.py`)。

## 2. 设计

### 2.1 凭据存储:复用,不新建

`TokenStorage` 的实现落在 `MCPServer.env` 已经在用的那条加密路
(`crypto.encrypt` / `crypto.decrypt`,`mcp_service.py:30-33`)。
🔴 **不新开一张表、不新开一条加密路** —— 那会变成 spec ⓪ 那一族的第六个消费者,
而 ⓪ 正在把这一族收敛成一条。

⇒ **排期上 ③ 的第三步应该在 ⓪ 之后**,否则新加的 token 存储会绕开 ⓪ 的三态。
(第一步、第二步与 ⓪ 无关,可并行。)

### 2.2 回环端口:按 RFC 8252 写动态端口

🔴 **用户裁决**:按 RFC 8252 设计 —— loopback 重定向本来就该允许
**127.0.0.1 任意端口**,**spec 按动态端口回环写**;
哪家 provider 不守 RFC、要求固定端口,**逐家记例外**,
**不要为少数派把全局设计迁就成固定端口**。

具体:
- 授权开始时**临时**绑一个 `127.0.0.1:0`(内核给端口),
  redirect_uri 用那一次的实际端口。
- 拿到 code 后**立刻关掉**监听。不常驻。
- ⚠️ **不要复用 `choose_port()` / `DEFAULT_PORT`**(§0.7):那是主服务的端口,
  和 callback 是两件事,混用会让 redirect_uri 依赖主服务端口的选择结果。
- `state` 参数 + PKCE 都由 SDK 负责(§0.3),我们只负责把 code 递回去。

### 2.3 UI:三态而不是二分

`_one_click` 的二分(§0.5)扩成三类,**分区依据换成显式的 `auth` 字段**:

| 类别 | 徽标 | 动作 |
|---|---|---|
| `none` | 绿 one-click | Connect 按钮(今天的行为) |
| `static_key` | 琥珀 needs key | 预填表单(今天的行为) |
| `oauth` | **新** | 第一步:说明 + 无按钮;第三步:「授权」按钮 |

🔴 **每一个新字段都必须有一条渲染断言**(§0.5 末的 `containment` 前车之鉴)。

### 2.4 401 分类

`discovery.py` / `session.py` 捕获 `httpx.HTTPStatusError` 时按状态码分:
401/403 → 授权失败(并说明是静态 header 还是 OAuth)、其他 → 保持今天的行为。
⚠️ 分支顺序注意 `httpx` 的异常继承(spec ① §0.4 记录了同一个陷阱:
`HTTPStatusError` 和 `TimeoutException` 都是 `HTTPError` 的子类)。

## 5. 风险与未覆盖面

1. 🔴 **第三步的真实可用性取决于对方服务器**。SDK 走 authorization-code + PKCE
   (+ 可能的 DCR)。**一家不支持 DCR 的 provider 需要人工注册一个 client_id**,
   那是 UI 上的一整个新字段。⇒ 第三步动手前必须**先选定一个具体的目标 server 并实测它的
   `.well-known` 元数据**,不能先写代码再找对象。
2. **打包版 webview 开浏览器这件事没有验过**(§0.6)。它有可能让第二步的
   工作量从「加一个命令」变成「加一个命令 + 修一个既存缺陷」。
3. **未覆盖:设备码**(SDK 没有)。若目标 server 只给设备码,**记例外**。
4. **未覆盖:token 撤销 / 断开授权的 UI**。第三步只做「连上」,不做「断开」。
5. **未覆盖:多账号**(同一个 server 两个身份)。
6. `test_mcp_catalog.py:71` 的 `len(data) == 10` 是一个**故意的 lockstep 闸**,
   不是要绕过的东西。
