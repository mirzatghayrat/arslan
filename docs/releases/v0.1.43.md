## Background work finishes instead of being cut off

In 0.1.42 a background job had the same small budget as a single chat answer
and was stopped the moment it ran out — research jobs could end halfway with
nothing to show.

后台作业不再做到一半被掐断：到了预算就收尾，用已经查到的内容把结果写出来。

- Each job now has its own budget. **Settings → Advanced → Background work
  budget** offers Lean, Standard (default) and Ample; the page shows each
  tier's numbers. Standard: 120 model requests, 80 tool calls, 600k tokens,
  30 minutes.
- Reaching the tier is not a failure. Arslan stops looking things up and
  writes the result from what it already has (it can still save the file you
  asked for). The usual completion checks then decide Done / Partly done.
- Only a job that cannot stop itself is halted, at 1.5× the tier. The card and
  one message then say which limit ran out and how to continue.
- The card no longer shows internal codes, and criteria a job never reached
  say so instead of "not checked yet".
- Asking "how is it going?" reads the job's real state.

## Known limitations

Unchanged from 0.1.42: asking an expert still runs in the foreground; two
confirmations of the same kind at once show one at a time.

## Upgrade

No database migration; upgrading from 0.1.42 creates no automatic backup.
