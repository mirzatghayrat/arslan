## Arslan can act: its own browser, and your Mac

Arslan 现在能动手了：它有自己的浏览器，也能用「快捷指令」和 AppleScript 操作你的 Mac。

**Arslan's browser.** A browser window you can watch, with its own profile.
Arslan can open public web pages and read them in any conversation. When a
piece of work needs clicking, typing or choosing options, Arslan does it as
background work:

- The first action on each website asks you once (a card in the window and a
  notification). After that, that piece of work continues on that site.
- **Arslan never types passwords.** If a site needs you to be signed in, sign
  in yourself in the Arslan browser window; it remembers the session.
- It reaches public websites only (not your local network), downloads and file
  uploads are off, and it cannot run its own scripts in pages.
- One-time setup: Settings → Advanced → Browser setup (downloads the browser).

**Your Mac.**

- Arslan can list your Shortcuts and, in background work, run one — it asks
  once per Shortcut.
- It can run an AppleScript to work with apps such as Reminders, Calendar or
  Notes. It shows you the full script and asks every time. The first time a
  script controls an app, macOS also asks you.

Only a click in the window approves any of this; nothing spoken does.

## Known limitations

- One browser window is shared by all work; two jobs using it at once take
  turns.
- If a confirmation of the same kind is already on screen, the next one waits
  for it.
