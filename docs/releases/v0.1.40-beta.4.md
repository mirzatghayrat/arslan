# Arslan 0.1.40-beta.4 — identity and trust clarity

> **Back up before installing. This preview shares stable Arslan's application
> identity and data directory. Opening it can upgrade the database in place
> (including migrations 0047–0053); there is no general downgrade guard. Keep
> your prior app, pre-upgrade profile and matching secret/key material separately.
> Reinstalling an older app alone is NOT a safe rollback. Restore its matching
> profile and key too. If you cannot preserve these, do not install.**

Publish only as **Pre-release**, never Latest. Final Publish belongs to the user.

## Changes since beta.3

- Settings identifies the running desktop version and stable/preview status.
  Browser clients and unreadable native versions are explicitly labelled; the
  backend's independent version is never substituted for the installed app.
- Preview users see that automatic updates follow the stable channel and that
  preview installers require manual installation.
- A previewable, click-to-copy version summary contains only client type,
  version and channel. It does not upload anything or include chats, settings,
  credentials, filesystem paths or task logs. It is not a full diagnostic bundle.
- All six interface locales include these messages.
- README security descriptions no longer advertise the unfinished credential
  broker; the outdated safety illustration is replaced by the boundary record.

## Scope and limitations

This is a small clarity update, not completed companion v1.2. No new database
migration, model routing, runtime download or authenticated workflow is added.
The read-only native version permission does not grant filesystem or account access.

Beta.3 limits remain: public read-only browser operation; no authenticated
browser/form/upload workflows; sampled video frames, not full motion analysis
or an audio transcription backend; incomplete real-model quality, full locale
and old-data matrix, and independent security acceptance. The separate analysis
Python runtime is retained. The 12-case next-stage pilot is selected, not executed.
