## Work happens in the background; the conversation stays free

When you ask for something that takes work, Arslan says in one line what it
will do and what "done" means, starts it in the background, and hands the
conversation straight back — you can keep typing, or keep talking in voice
conversation. A card in the chat shows the job: its completion criteria, the
current step, and a Stop button.

需要动手的事，Arslan 会用一句话接下、说清楚怎样算完成，然后放到后台去做，对话立刻还给你——可以继续打字，也可以继续语音对话。聊天里有一张卡片显示这件事的完成标准、当前步骤和「停止」按钮。

- When it finishes, the result arrives as a new message in the same
  conversation, labelled with the checked outcome: **Done** (every criterion
  checked), **Partly done**, **Stuck** (with what is missing) or **Stopped**.
  With the window hidden, macOS notifies you. In voice conversation Arslan
  says one sentence.
- Ask "how is it going?" or "stop that" at any time.
- Up to 3 jobs run at once; more wait their turn.
- If a job needs your confirmation (writing a file, running a command,
  creating a schedule), the card waits in the window and macOS notifies you.
  Only a click approves; in voice conversation Arslan only reminds you. A job
  never reuses "remember for this session", and an unanswered card is
  declined after 5 minutes, as before.
- Jobs run inside Arslan. Quitting Arslan stops them; at the next start the
  conversation says which job was interrupted, and nothing more is done.

## Plain answers are no longer tasks

A normal answer no longer waits for your review, and no longer appears in a
task list. The sidebar shows **In progress N** only while background jobs run.
Answers from earlier versions are left as they were in your data; they are
simply no longer shown as open tasks.

## A quieter window

- The conversation header is one row: title, project (click for project and
  memory settings), and a status chip only when something needs a look.
- "View replay" moved into each answer's ⋯ menu.
- Experts are no longer a standing cast in the chat: when Arslan asks one to
  help, one short line says so. Manage experts in Capabilities.
- The command-confirmation setting lives in Settings → Advanced; under the
  message box a single line remains only when read-only commands run without
  asking. Browser setup and static preview also moved to Settings → Advanced.
- The Chinese interface says 专家 everywhere (no more 分身).

## Known limitations

- Asking an expert still runs in the foreground and holds the conversation
  until it finishes; only Arslan's own work goes to the background here.
- Whether a task becomes background work is Arslan's judgment; if it answers
  directly instead, ask it to do it in the background.
- Two confirmations of the same kind at once show one at a time.

跨语言或多文档对比时，模型可能错误地断言某份文档缺少某项内容；请打开来源核对。

The 0.1.40 R4 limitation is unchanged.

## Upgrade

0.1.42 adds two database migrations (0054, 0055), so upgrading creates the
automatic pre-upgrade backup first, as described in the 0.1.40 notes. No
existing row is rewritten: 0054 changes an index, 0055 adds a nullable column.
