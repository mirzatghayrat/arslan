# Arslan 0.1.40-beta.1 — personal companion preview

This is an opt-in preview, not the completed personal companion v1.2 release.
Keep this release marked **Pre-release** when publishing. It must not replace
the stable channel's Latest release. Existing 0.1.39 draft remains separate.

## Included

- Updated workspace navigation, project/memory/task surfaces and Lucide icons.
- Resizable browser/artifact side panel with temporary-conversation isolation.
- Isolated public-page navigation, links, history, refresh, scrolling and page
  text. This browser mode is read-only, not general form or account automation.
- Declared document/code/image/URL/video input capabilities, source locators,
  bounded extraction and explicit missing-capability errors.
- Six-language interface resources and focused native language/restart checks.
- Attachment draft retention fixes, private/numeric URL handling, packaged
  webpage extraction resources and retryable browser-stop ownership.

## Important limitations

- Credential-backed account workflows and browser login/form/upload actions
  are not enabled or certified. Independent security acceptance is unfinished.
- Video uses sampled frames; this is not full-motion understanding. Audio
  transcription requires a backend that this preview does not provide.
- Complete locale/layout/old-data and native recovery edge-case acceptance is
  unfinished. Custom durable-key recovery configurations remain restricted.
- Synthetic/local tests are not real-provider reasoning or media-quality
  benchmarks. Available model behavior depends on the user's configuration.

## Before installation and rollback

Create and retain a verified backup of the existing profile and its matching
secret material using the established backup process. Keep secrets separate from
the release/download and never attach them to an issue. Installing this preview
uses the normal Arslan application identity; it is not a separate stable-profile
sandbox. Do not overwrite the only copy of an existing installation or data.

An older app must not be pointed at a preview-modified database without explicit
compatibility evidence. A rollback means restoring the retained prior app and
its matching pre-preview profile/key through the established recovery process,
not merely installing an older binary over newer data.

## Maintainer publication checklist (not yet completed)

- Refresh the temporary candidate for the final reader-stop change and version;
  verify startup, draft/data retention and stop/retry behavior.
- Check advertised capability boundaries remain enforced.
- Confirm the signed/notarized Apple Silicon DMG, updater signatures and fresh
  install checks pass for the exact tagged source. Unsigned temporary apps are
  validation artifacts, not the distributable release.
- Attach these notes to the generated draft; retain Pre-release and non-Latest
  status; inspect artifact identity and checksums before the human Publish step.
