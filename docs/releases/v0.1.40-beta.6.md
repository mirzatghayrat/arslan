# Arslan 0.1.40-beta.6 — refined identity and visual polish

This preview follows beta.5 and retains its research and continuity improvements.
Install manually; the stable auto-update channel remains unchanged.

## Changes

- Refined Bengal-cat silhouette with a tapered face, soft silver frosted-glass finish,
  warm orange light and recessed branching detail. Updated desktop icons, in-app
  marks and browser icons together.
- Settings → Appearance & Language now offers Frosted Orange and Pure Monochrome
  icons. The selection persists across restarts and updates the running Dock icon
  and in-app marks. Finder/Launchpad keep the bundled default icon.
- Fixed splash-window corners in WebKit: video, fade and error states are clipped
  to genuinely transparent rounded corners. The existing animation is preserved.
- Improved typography, spacing and wrapping in settings, the welcome screen and
  sidebar. Fixed narrow-window expert status badges splitting across lines.

## Compatibility

This is a **Pre-release**, not Stable Latest. It shares the application identity
and data directory with stable Arslan. Back up the existing profile and matching
secret/key material before installing a preview; downgrading the app alone does
not roll back its database. No new database migration is introduced by beta.6.
The research/model-quality and companion-preview limitations documented in
beta.5 still apply.

## Verification

Local checks: TypeScript and production build passed; 2,032 frontend tests passed;
78 Rust tests passed with one existing ignored test; four native command-permission
checks passed. Isolated native preview verified icon switching and restoration.
WebKit screenshots verified transparent corners during video, fade and error
states; five main pages were inspected at 1280×840 and 900×600.

Publication requires successful CI for the exact tagged source, signed and
notarized packaging, fresh-install acceptance and uploaded-asset verification.
Final release evidence is added to the published notes after those checks.
