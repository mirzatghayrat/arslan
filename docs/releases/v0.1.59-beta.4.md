## Arslan 0.1.59 beta 4 — Desktop, Documents and Downloads stay closed when you say so

A preview of 0.1.59: Arslan 0.1.58 plus the fixes below. It is a pre-release, so Arslan's automatic update stays on 0.1.58; download it here to try it. When 0.1.59 comes out, this version updates to it.

**Desktop, Documents, Downloads: Off now means off for commands too.** Before, the switch kept Arslan's file tools out of these folders, but a command (ls, find, a script) could still read them — a question from the iPhone could make Arslan look through your real Downloads. Now commands cannot open them either while the switch is off; your working folder and project folders kept inside them still work. A command you let run outside the sandbox (you are asked each time) is not confined.

**Background work that did the job counts as done.**
- A job that saves into a folder you named — "copy this year's invoices into ~/Invoices" — is checked on the disk: the folder must hold files created or changed during the job. Before, only files Arslan wrote itself counted, so such a job could never finish as done.
- "Read my notes and tell me…" counts the files Arslan read, not only web pages.
- A command that simply failed — a probe for a missing folder, a script that exited with an error — no longer marks the whole job as "needs your review", and Arslan may try the same command again after fixing something. Commands that send something off this Mac (uploads, git push, ssh, mail, other apps), commands stopped by their time limit, and every other kind of failure still ask you to check.

**Arslan in the background keeps working.** A long task that asks for your approval while Arslan is not in front no longer ends with "Model error": the card waits in the Inbox, on the island, or in the window when you come back.

**No ghost replies.** After a reconnect, a finished answer is not shown a second time, and no "working" row is left with a timer running.

**The island shows plain text** — no stray asterisks or backticks in a job's result.

**From beta 2:** Arslan answers in the language you write in; provider names are English; a job that ends early says why in words.

**Known limits:**
- A local script that sends something over the network itself and then fails is treated as a local failure.
- A message that is only a short word in a Latin script ("ok") follows the conversation's language.
