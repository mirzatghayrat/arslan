# Arslan 0.1.40-beta.2 — personal companion preview

Opt-in preview only; the full companion v1.2 upgrade is not complete. Preserve
**Pre-release** and **not Latest** when publishing. No automatic publication.

## Included

Workspace/project/memory/task improvements, Lucide icons, a resizable browser
and artifact panel, isolated read-only public browsing, expanded bounded file
input with source locators, six-language resources, attachment draft retention,
webpage extraction fixes and retryable browser-stop ownership.

This supersedes the unshipped beta.1 candidate. Its cloud build was cancelled
after GitHub reported AnyIO security advisories affecting locked version 4.14.1.
The lockfile now uses 4.14.2, the advisory's patched release; no other dependency
was changed. The existing beta.1 tag is retained and was not moved.

## Limitations and safe installation

- Browser mode supports public navigation, links, history and scrolling, not
  login, form submission, uploads or credential-backed account automation.
- Video uses sampled frames, not full-motion analysis; transcription is absent.
- Complete locale/layout/old-data, recovery edge-case and independent security
  acceptance remains unfinished. Synthetic tests are not model-quality results.
- This uses the normal Arslan application identity/profile. Back up the prior
  app, data and matching secret separately before opting in. For rollback, use
  the retained prior app with its matching pre-preview data/key; do not assume
  an older app can read a database modified by this preview.

## Publication gate

Only publish after the exact beta.2 source completes signed/notarized macOS
Apple Silicon packaging and fresh-install checks. Verify attached DMG, updater
signature and manifest. The earlier local beta.1 candidate passed 65 install
checks and normal browser stop/reopen; those are prior scoped evidence, not a
claim that beta.2 cloud artifacts are already verified. The glib advisory is
not in the resolved `aarch64-apple-darwin` dependency graph (verified with offline
Cargo reverse-dependency resolution); this does not clear other platforms.
After upgrading AnyIO, 90 focused packaging/install-probe/browser/release tests
passed. No broad test rerun or completed cloud artifact verification is implied.

The final Publish action remains with the user.
