## Arslan 0.1.50 — keeps the work on track

Measured on the same model as before (deepseek-v4-pro) before shipping.

**What changed**
- **Finds another way when one is blocked.** When macOS refuses AppleScript, Arslan now goes straight to another route (a Swift script with EventKit, or a Shortcut) instead of retrying or handing back.
- **Knows what it can do.** It no longer says "I can't save files" when it can; saving in its own folder needs no permission, and missing folders are created.
- **Keeps the thread on long tasks.** Each step ends with a short note of current facts (folder, files saved, plan, work so far), and it can keep a checklist ("collect jobs 6/10"). The model's cached context is reused across steps, which saves cost.
- **Finishes instead of stopping empty.** If research stalls or its page-reading allowance runs out, it saves what it has first; when it reaches the turn's limit after real work, it tells you what was saved and where, and you can say "continue".
- **Links that hold up.** After saving a table of links, rows that share a link or use one it never actually saw are flagged so it opens or replaces them; fallback answers keep each item's link.
- **Activity, redesigned.** Activity sits where "Local service · Online" was (the connection shows only when something is wrong). The page now opens with usage: runs, success rate, P95 time, tokens and cost, a time-taken heatmap and results over time, and usage by model — then scheduled tasks, then recent work with status and duration.
