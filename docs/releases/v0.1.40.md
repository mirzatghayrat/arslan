# Arslan 0.1.40

## Upgrade safety — read before installing

HOLD: not ready to publish. Implementation and candidate/package verification
are pending; the statements below must be verified before this hold is removed.

This version upgrades the database when migrations are pending. Before those
migrations it automatically creates a checksummed backup in the data directory's
`backups/` folder and retains the latest three automatic upgrade backups.
On macOS the default is `~/Library/Application Support/Arslan/backups/`.
If backup fails, migration must not proceed. Backups do **not** include the
external encryption key. Keep that key separately and securely.

To return to 0.1.38, stop Arslan and restore a **pre-0.1.40 upgrade backup** using
the **same encryption key**, then open the restored profile with 0.1.38. Merely
reinstalling the old app over an upgraded database is not a supported rollback.
A backup made after upgrading is not a substitute for the pre-upgrade backup.
