## Arslan 0.1.54 — ready for Arslan for iPhone, and a stricter terminal gate

**Arslan for iPhone, Mac side.** Everything the iPhone app needs on the Mac:
- **Touch ID approvals count.** An iPhone that approves with Touch ID (iPhone SE) is now accepted; before, the Mac treated that yes as a cancel. The Mac tells the phone it accepts Touch ID.
- **One phone, one entry.** When the same iPhone pairs again, it replaces its old entry in Settings › iPhone instead of adding another, and nothing is kept in your iCloud for the old one.
- **Removing a phone cleans up after it.** Messages the Mac had left for that phone are deleted from your iCloud. At start-up the Mac also clears what is still waiting for phones that are no longer paired.
- **See where pairing is.** Settings › iPhone shows each phone as *Connecting…* until the Mac hears from it, then *Connected* with when it was last seen.
- **A finished task stays finished on the phone.** A step the Mac was holding back no longer arrives after the task ended, so the phone does not show "working" again.

**A stricter terminal gate.** Four gaps closed; every change asks more, none less:
- A command that matches several rules skips its card only when you said "don't ask again" to every one of them, not just the first.
- Each command in a chain (`&&`, `;`, `|`, `||`, `&`) is checked, not only the first.
- The local access token is given only to a caller that already has it.
- Background jobs no longer inherit a conversation's "run outside the sandbox" grant; they stay sandboxed.

**Privacy wording.** The privacy policy, site and READMEs say exactly when left-over iPhone-link records go: older than 7 days, checked about once a day while Arslan for Mac is running and online. The READMEs also now say plainly that shell commands still run (marked as unsandboxed) when the workspace sandbox cannot start; generated Python is refused.

**Under the hood.** Tests no longer share a database session by accident, which made one CI check flaky in 0.1.53.

The iPhone app itself is coming to the App Store.
