## Arslan 0.1.59 beta 2 — English answers to English requests

A preview of 0.1.59: Arslan 0.1.58 plus one fix. It is a pre-release, so Arslan's automatic update stays on 0.1.58; download it here to try it. When 0.1.59 comes out, this version updates to it.

**Arslan answers in the language you write in.**
- An English request could come back in Chinese, together with the background job's title, its checks and the "Learned" line after it. Now every message tells the model which language to answer in, taken from what you wrote; paths and file names do not count. A message with no words (just a path) follows the interface language.
- Text Arslan reads while it works (tool results, hints) is in English, and nothing in its fixed instructions is in Chinese any more.

**No Chinese in the English interface.**
- Provider names are English: "OpenRouter (Claude, Gemini and more)", "Qwen (Alibaba Cloud)", "Zhipu GLM", "Ollama (local)", "OpenAI-compatible (custom)". Providers you already added are renamed too, unless you gave them a name of your own.
- A background job that ends early says why in words, never as a code like "task_reconciliation_required".

**Known limits:**
- A message that is only a short word in a Latin script ("ok") follows the conversation; Arslan is told it is not Chinese.
- Chinese text written for a Chinese request (the "reply continue" note, findings headers) stays Chinese, as intended.
