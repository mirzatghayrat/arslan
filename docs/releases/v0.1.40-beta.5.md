## Changes since published beta.3

- Settings shows the actual running desktop version and preview/stable channel,
  with a previewable copy-only identity summary. No chats, credentials or paths
  are included, and nothing is uploaded. This includes the unpublished beta.4
  source improvements; beta.4 does not need a separate installation.
- Research answers retain bounded source links with explicit supplied/unread,
  read, or partially read labels. Those labels do not certify the conclusions.
  Credential-bearing URLs are omitted; strict output-only requests keep their
  requested format instead of receiving an appended source footer.
- Stronger instructions preserve document locators and unknown calendar dates,
  and avoid inventing project status, owners or reporting periods.
- Word extraction excludes deleted/moved-from text and discloses tracked
  revisions. This is current-text extraction, not a full revision renderer.
- Damaged research trace records are treated as unread instead of crashing
  evidence checks; unrelated valid sources remain available.

## Evidence and known limitations

A bounded primary-model pilot used 32 requests on synthetic inputs and pinned
public sources. It exercised file write/read-back, project memory isolation,
correction/deletion, real summary regeneration and explicit recovery after a
simulated interruption. Baseline failures and repair attempts are retained.
See `docs/companion/stage-2-live-baseline.md` for the case-by-case boundaries.

**This is not a 12/12 full-pilot pass or completed companion v1.2.** The genuine
public-conflict case remains blocked; some public evidence was truncated or
provided as excerpts. Source links are navigation, not automatic fact checking.
Live interrupted recovery was read-only; uncertain-effect replay is covered by
separate deterministic tests, not real external account writes. Model quality
is not guaranteed by unit-test counts. Native UI and broader independent
security/usefulness acceptance remain limited.

No new database migration, training, model router, runtime download, general
browser write permission or authenticated account workflow is introduced.
Beta.3 limitations remain, including sampled video frames rather than complete
motion/audio analysis and the retained separate analysis Python runtime.
