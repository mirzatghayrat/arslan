## One Arslan

Arslan now does the work itself. Experts are no longer created, invited,
routed to or shown in the chat.

现在只有一个 Arslan：它自己干活，不再建专家、派活给专家，聊天里也不再出现专家。

- **Your former experts are not lost.** Capabilities → **Former experts** lists
  them; **Turn into skill** (or **Convert all**) keeps each expert's method as a
  skill. Arslan reads a skill whenever the work matches. Nothing is deleted.
- **Scheduled tasks** are run by Arslan. Existing ones keep their name, prompt
  and schedule; the form no longer asks for an expert.
- The sidebar lists conversations only; its **+** starts a new conversation.

## A failed look-up no longer stops the work

Before, if a read-only step failed — for example a browser screenshot — Arslan
could stop the whole answer with "Model error — An action may already have
happened".

- Read-only steps (reading pages, searching, screenshots, read-only commands)
  can fail without stopping anything.
- If an action that changes something really has an unknown outcome, Arslan
  does not repeat it, keeps doing the rest, and then asks you to check that one
  action. The notice is titled **Needs your check**, not "Model error".

## Upgrade

One database migration (0056): scheduled tasks are set to run as Arslan. The
automatic pre-upgrade backup is created first.
