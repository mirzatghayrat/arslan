## Arslan 0.1.49 — a steadier execution layer

Measured against Hermes on the same model (deepseek-v4-pro, 3 runs per task) before shipping.

**What changed**
- **Native tool calling** for DeepSeek and other OpenAI-compatible models: real tool-call history with the model's reasoning passed back, instead of tool results disguised as user messages.
- **Long work no longer breaks off**: larger output budget for DeepSeek; a cut reply is re-sent or continued; a cut tool call is never executed.
- **Recovers from model-service hiccups**: rate limits and server errors are retried with backoff; errors always say what failed and what was tried — never an empty error.
- **Web search works out of the box again**: it now uses your model's built-in search (DeepSeek, same key). DuckDuckGo had started serving a "prove you are human" page that read as "no results".
- **Chat turns finish**: at the turn's limit Arslan stops researching and delivers what it has, instead of ending with an empty reply.
- Clearer handling of tool mistakes; long tool output kept in full on disk; streaming with a stall watchdog; several smaller fixes.

**Measured vs Hermes** (same model, 3 runs each)

| Task | Arslan | Hermes |
| --- | --- | --- |
| Research table with sources | 3/3 (cheaper) | 3/3 |
| Organise a Downloads folder | 3/3 | 3/3 |

**Known gaps (next version)**: trying a different route when the first is blocked; sometimes says it cannot write a file when it can; using pages you are logged into.
