# Arslan 0.1.39 — focused desktop settings

## Desktop settings

- A dedicated settings sidebar replaces the workspace sidebar while settings are open. Return to workspace preserves the current conversation.
- Model connections use flat rows, a default-model summary, a prominent Add model action, and inline editing.
- Task routing and advanced connection controls are collapsed on entry. All original configuration and connection-test actions remain available.
- Saved API keys remain hidden. Status badges reflect saved or live connection-test results; untested connections are never shown as healthy.
- New labels are translated in all six supported languages. Existing themes and native macOS window controls are preserved.

## Verification

- Frontend: 217 test files, 1,687 tests passing with the Node 22 CI runtime; TypeScript and production build checked.
- Native visual and interaction checks use a separate app copy and a clean data directory with local-only synthetic model connections.
- The release workflow builds the signed, notarized macOS Apple Silicon installer and runs the fresh-install checks. Verify the successful workflow before publishing this draft.

This update changes the settings experience, not the underlying model's reasoning quality. Local synthetic connection tests are not real-provider benchmarks. No running installation or existing user data is replaced by these checks.
