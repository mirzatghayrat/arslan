## Arslan 0.1.57 — capabilities that grow: Arslan finds what it lacks, asks, installs it safely, tests it, and tries again

**When a step needs something Arslan cannot do, it looks for it.** It searches the official MCP Registry, GitHub and reviewed skill libraries for something that does the job — for example reading the formulas in an Excel file, not just the values.

**Then it asks, in the conversation.** One card shows what it would add, where it comes from, its license (read from the project's own license file, not from a package listing), how it would run, which folder it may use, and any key it needs. **Add and retry** or **Not now**. Only the Arslan window that asked can say yes; a key typed on the card goes to Arslan's encrypted store, never into the conversation.

**Installed carefully, tested before it is switched on.**
- **Pinned:** a fixed version with a lock file and checksums. Python servers need no Python of yours, and Node servers no Node of yours: Arslan downloads its own pinned uv or Node once.
- **Nothing runs while installing:** Python packages only as ready-built wheels, npm packages without install scripts.
- **Scanned for known dangerous patterns:** hidden instructions in a skill, code that fetches and runs more code, writes to where macOS starts programs, a script that reads keychains or SSH keys. A dangerous finding removes it again. A scan cannot prove something safe, which is why everything also runs in a sandbox.
- **A sandbox that starts from no:** an installed server can use its own folder and the folders you gave it — nothing else in your home folder, never your SSH keys or Arslan's own data — and no network unless it needs a key for an online service.
- **Tested once:** it must start and offer its tools. Only then is it switched on, and Arslan retries the step that failed, in the same reply.

**Capabilities page.**
- **Discover** searches by what you want done, across all three sources, with the license, activity and how each would run.
- **Arslan found** keeps what Arslan found for later: a card you said not now to, a background job that hit a wall, or a project level that may need something. There is a quiet count beside Capabilities; it is never a notification.
- **Every added capability has a dossier:** license and where it was read, pinned version and checksum, scan, first test, the folders it may use (changeable), and **Check for a newer version**. That shows what changed first, and installs the new version beside the old one, keeping the old one until the new one passes.
- **Use in a project:** as material (its description and README go into the project's materials), or as a dependency (a project conversation opens with the request typed, not sent).

**Skills imported from GitHub** are now pinned to one commit, with a checksum for each file. When Arslan reads one, it treats the text like a web page: it cannot give Arslan new permissions.

**Hands:** groundwork for a second engine, not switched on. The current engine stays.

**Known limits:**
- Python bundles in the MCP bundle format (mcpb) are not installed yet.
- Servers you added by hand are not moved into the sandbox in this version.
- Clicking the island still brings Arslan to the front.
