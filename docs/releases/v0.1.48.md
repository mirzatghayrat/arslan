## One assistant that gets things done

Arslan 现在是一个真正能动手的助手：一条对话回路、自己的文件夹、默认可用的终端，该问的才问。

- **One loop, no pre-turn router.** Every message goes straight to the agent,
  which decides for itself whether to answer, use a tool or start background
  work. The canned replies some requests used to get ("I can't set reminders")
  came from the router's guess, not from what Arslan could actually do. Facts
  worth remembering are noted after the answer instead.
- **Arslan's own folder, `~/Arslan`.** Files Arslan makes go there, and it
  writes there without asking. A folder you choose yourself in Settings asks
  once per conversation before the first write.
- **The terminal is on by default.** Arslan runs everyday commands (reading,
  converting, building, running scripts) without a card. It **asks first**
  before anything that sends, posts, uploads, deletes, installs, publishes or
  controls another app. It **never** reads passwords out of the keychain,
  touches its own key files, uses `sudo` or deletes system folders. The
  destructive-command detection is Hermes Agent's (MIT, vendored); the rules
  about acting in your name are Arslan's own.
- **"Don't ask again" means a kind of command, and you can take it back.**
  Ticking it on a command card remembers that kind (for example "installs
  software"). Settings › Advanced › Terminal lists every one with **Ask again**.
  Background jobs honour what you allowed but never add to it.
- **The browser sets itself up** the first time Arslan needs it.
- **It describes itself truthfully:** no talk of a team or experts it does not
  have.

## A cleaner app

- **Right panel = this task.** Background work for this conversation, the
  files Arslan saved (open, or show in Finder), and the working folder.
- **Activity replaces Diagnostics.** Recent work, newest first, where every
  answer and background job opens into its step-by-step run (tools, files,
  approvals), plus usage and scheduled tasks.
- **Sidebar:** Connections is now a tab in Capabilities; no expert rows.
- **Settings:** the "read replies aloud" switch is gone. Replies are spoken
  while a voice conversation is running, and only then. Spawn mode and
  auto-evolution are gone with the experts. The "Request routing" model slot
  is now called "Remembering facts", which is what it does.
- **Chat:** old expert messages keep their text, copy and run link; the expert
  buttons that no longer worked (confirm direction, 👍/👎, refine, invite) are
  gone.

## Fixed

- On a fresh install Settings showed the terminal switched **off** and set to
  "ask for everything" while it was actually on and asking only for risky
  commands. It now shows what is really in effect.

## Upgrade

No database migration. Former experts are still listed under Capabilities ›
Former experts, where each can be turned into a skill.
