## Arslan 0.1.53 — hands for your Mac apps

**Arslan Hands.** Arslan can now read and use the apps on your Mac — Notes, Mail, Pages and the rest — through a small helper, Arslan Hands. It reads an app's window as its accessibility tree (never a screenshot) and acts in the background: your mouse, keyboard and front window stay yours. The first time it is used, macOS asks you to allow "Arslan Hands" under Privacy & Security › Accessibility; Arslan itself never holds that permission.

**Asked, not assumed.** Looking at an app asks once per app in a conversation. Acting happens only in background work and asks once per app; a button that deletes, sends, pays, buys, transfers or submits asks every time. Password fields are never typed into, and some apps are never touched: Keychain Access, password managers, System Settings, macOS security prompts, Notification Center and Arslan itself. Web browsers are only read (Arslan's own browser acts on web pages); terminals and code editors are only clicked and scrolled. Settings › Desktop shows the lists and lets you add apps.

**Seen and stoppable.** A labelled cursor shows what Arslan is doing, the notch island shows the current step with a Stop button, the menu bar has "Stop Arslan's hands", and Activity lists the last seven days of Hands actions (typed text is recorded only as a length).

**Files go the direct way.** Renaming, moving or copying files is done with a command, not by clicking through Finder.

**Arslan for iPhone.** The Mac side is in: Settings › iPhone. The iPhone app is coming to the App Store.

**New icon.** Black and white is now the default; Frosted amber is still in Settings › Appearance & Language.

**Fixed.**
- A tool that waits for your answer no longer gives up after 20 seconds. Before, an unanswered card for an AppleScript, a Shortcut, a website or a Mac app was dropped and asked again — the "it keeps asking" some of you saw.
- If macOS refuses Arslan Hands, Arslan stops and tells you how to allow it instead of asking you, script by script, to do the job another way.
- A task that did not get done says so ("Not done", in yellow) instead of looking finished.

### Known limits
- Hands sees windows on the current desktop only; an app on another Space, or behind a full-screen app, counts as not open.
- Large windows (Notes with many notes) can take 10–20 seconds to read.
