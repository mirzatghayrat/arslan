## Arslan 0.1.59 — a chat that keeps up, answers in your language, work that counts as done

**A long answer is not "Interrupted", and a second message waits its turn.**
- While Arslan works, the window hears from it at least every 15 seconds, even when the model spends minutes writing one long file. "Interrupted" now means the connection itself was lost, and it says what to do.
- A message sent while Arslan is still answering waits and is answered right after, instead of being refused and lost.
- The working line says what is true — "Thinking…", then after a quiet minute "Still working — a long answer can take a few minutes" — instead of rotating phrases.
- Approving or declining a Hands card in the window during a reply takes effect at once; before, the answer could go unread until the card expired.
- The model under the composer reads "OpenRouter · model", so the model name fits.

**Arslan answers in the language you write in** — an English request could come back in Chinese. Provider names are English too, and a job that ends early says why in words, never as a code.

**Background work that did the job counts as done.**
- A job that saves into a folder you named is checked on the disk; "read my notes and tell me…" counts the files Arslan read.
- A command that simply failed (a probe for a missing folder, a script that exited with an error) no longer sends the whole job to "needs your review", and Arslan may try it again after fixing something. Commands that send something off this Mac still ask you to check.

**Desktop, Documents, Downloads: Off means off for commands too.** Commands (ls, find, a script) cannot open these folders while the switch is off; your working folder and project folders kept inside them still work.

**Arslan in the background keeps working.** A long task that asks for your approval while Arslan is not in front waits in the Inbox, on the island, or in the window — no "Model error". After a reconnect a finished answer is not shown twice, and the island shows plain text.

**Known limits:**
- While the model writes one long file, the window shows that it is still working, not yet which file.
- A command you let run outside the sandbox (you are asked each time) is not confined by the folder switch.
- A local script that sends something over the network itself and then fails is treated as a local failure.
- A message that is only a short Latin-script word ("ok") follows the conversation's language.
