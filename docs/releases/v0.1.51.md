## Arslan 0.1.51 — Arslan in the notch, and commands in a sandbox

**Arslan Island.** A small Arslan lives in the notch (a short bar on screens without one). While work runs it shows the task and how far along it is; hover for the plan and the last steps. It opens by itself when something needs your OK, says "done" for a few seconds, and tells you when a task stopped. Never in screenshots or screen sharing; click-through everywhere except the island. Settings → Desktop → "Show Arslan in the notch".

**Command sandbox.** Commands Arslan runs can read files and use the network, but write only inside its working folder, temp and cache folders, and can never read your SSH keys, keychain files or Arslan's own data and keys. Leaving the sandbox is always your click (up front with a reason, or "run again outside" after a stop; a checkbox allows it for the rest of the conversation). Settings → Advanced → "Run commands in a sandbox".
