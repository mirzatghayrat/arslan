# Arslan 0.1.40-beta.3 — personal companion preview

> **Back up before installing. This beta uses the same application identity and
> data directory as stable Arslan. First launch upgrades that database in place
> (including migrations 0047–0053); there is no general downgrade guard. Keep a
> verified copy of your prior app, pre-upgrade profile and matching secret/key
> material separately. Reinstalling 0.1.38 alone is NOT a safe rollback: restore
> the matching old profile/key too. If you cannot preserve these, do not install.**

This is an opt-in, limited preview, not completed companion v1.2. Publish only
as **Pre-release**, never Latest. The final Publish action belongs to the user.

## Changes

- Project/memory/task workspace improvements and consistent Lucide icons.
- Resizable browser/artifact panel, public read-only browser navigation and
  source-linked document/code/image/URL/video inputs.
- Six-language resources, attachment draft retention, corrected packaged
  webpage extraction and browser stop/retry ownership.
- AnyIO 4.14.2 security fixes. Clippy issues and stale generated capability
  inventory corrected; shared test fixtures and exact prose scanner false
  positive corrected without removing test/security gates.
- Release builds now require successful CI for their exact commit before
  signing starts. Existing beta.1/beta.2 tags are not moved or reused.

## Limitations

- No browser login/form submission/uploads or credential-backed account
  automation. Public browsing still contacts websites; it is not a reviewed
  credential broker or a claim that GET requests have no side effects.
- Video uses sampled frames, not continuous motion understanding; no supplied
  audio transcription backend. Real model/media quality is not certified.
- Full locale/layout/old-data, native recovery edge-case and independent
  security acceptance remain incomplete. Custom-key recovery is restricted.
- The larger installer contains a separate Python runtime with analysis
  libraries for isolated execution. This is intentional, not size-optimized;
  it does not grant unrestricted access to host files.
