## Arslan 0.1.58 — replies you can read, files you can open, any model you like

**Replies read like an answer, not a log.**
- What Arslan did while working is one quiet line under the reply — "6 steps · 48s" — that opens into plain sentences ("searched the web for …", "wrote 报告/汇总.csv"), with the notes Arslan wrote between steps. The raw tool details are still there for those who want them: Settings → General → Show technical details.
- While it works you see the last few steps live, and how long it has been going.
- Copy, the model and the tokens sit in one small row under the reply; the model opens a card with the calls, tokens and cost of that turn. The "main assistant" badge is gone.
- All of it is still there after you reopen the conversation.

**Files Arslan writes come back as files.**
- A file written during a turn shows under the reply as a card: name, kind and size, with Preview and ⋯ (download, copy path). More than three are one click away.
- Paths in a reply are clickable: a file opens in Arslan, a folder in the file browser, anything Arslan may not read can still be shown in Finder. A path that does not exist says so.

**One workbench on the right: Task, Files, Browser.**
- **Files** browses the conversation's project folder (or your Arslan workspace) and lists what this conversation produced.
- **The reader** shows text and code, Markdown, CSV and Excel as tables, images, audio, video, PDF, Word and RTF, and HTML — HTML only in a sandbox where its scripts cannot run. From the reader you can copy, download, or add the file to the conversation — and, for a file on disk, open it in its app or show it in Finder.
- Arslan reads only where its own read tools may: your workspace, Desktop/Documents/Downloads when default read is on, active project folders and its own outputs. Hidden files and credential-like names are never shown.

**Projects.**
- Project conversations appear under their project in the sidebar; a conversation can be moved into a project from its menu.
- **A level is no longer cleared past open work.** Clearing a level with open checkpoints asks first: move them to the next level, or drop them — and either can be undone. Arslan's own automatic advance only happens when nothing is open.

**Models: any model of any provider.**
- The model under the composer picks any model your providers offer — OpenRouter's whole catalog included — for this conversation, from the next message on. **Set as default** makes it the model new conversations start with. A ring beside it shows how full the context is.
- The picker searches every provider at once, keeps ★ favourites on top, and shows context length, price per million tokens and what each model can do. A model a role cannot use (no tools, or cannot see images) is greyed out with the reason.
- **Model roles** in Settings starts with the main model, and every role can name one model of its provider.

**Activity.**
- The usage chart answers when you point at it (calls, tokens, cost, models, how long) and filters Recent work when you click a day.
- Recent work, Hands and the judgment log scroll in their own boxes, 20 at a time, with icons for where each run came from; coming back from an opened run returns to the same row.

**Known limits:**
- A reopened conversation shows the context ring again only after its next message.
- Model favourites are kept on this Mac only.
- Whether the packaged app's viewer shows every PDF inline is not yet checked on a real Mac; "show as images" is there as a fallback.
- Clicking the island still brings Arslan to the front.
