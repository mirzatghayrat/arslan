How it works

One host. As many spawns as you raise.

It routes work to persona spawns you raised yourself — drafted from a persona seed library, named by you, kept on your roster. There is no fixed cast: raise as many as your work needs.

each spawn equips → tools · SKILL.md skill packs · MCP servers

Self-evolution, with an exam

Prompts improve on their own — but every change must pass a held-out exam.

win ≥ 60% on 10+ held-out tasks · judged blind, positions swapped

  • No dimension may score worse than the incumbent.
  • A candidate cannot win by getting longer.
  • The holdout is enforced in code, not by convention.
  • Real and synthetic win-rates are never merged into one number.
  • Fail → discarded, you never see it. Pass → a readable diff, in your inbox.

Nothing ships until you press Promote.

The promise guard

“I have handed that to Deck Master — generating now, one moment.”

0 dispatches. Nothing was handed to anything.

Every agent user has been lied to exactly like this. Arslan intercepts it with a deterministic check — not another model call. If a reply claims a hand-off the ledger doesn't show, it gets one rewrite; if it promises again, an honest template goes out instead.

Arslan cannot tell you it did something it did not do.

Second brain

Memory with a time axis.

  • [[wiki-link]] notes, as a force-directed graph.
  • Hybrid FTS5 + embedding retrieval.
  • Every belief records when it took effect and what superseded it.
  • Scrub the graph back to any past instant.

Safety is built in, not disclaimed

Everything that can spend or write is off by default.

From the shipped Settings page, verbatim: “They are all off by default and none of them changes anything without you.”

  • Generated code runs network-denied under the macOS kernel sandbox.
  • No kernel sandbox available? It fails closed, not open.
  • A local proxy injects git credentials — raw tokens never enter the sandbox.
  • Memory the model wants to delete goes to an inbox — never applied silently.
  • Your machine · your keys · zero third-party servers in the middle.

Honest limitations

Pre-v1, and it says so.

  • macOS 11+ on Apple Silicon only, for now.
  • Bring your own model API key — Arslan runs against your account.
  • Auto-evolution spends API credits and has no cap yet; the product itself tells you to set a hard spend limit at your provider first.
