# 体感验收：11 条（每次发版前，你亲手过一遍）

- **是什么：** 总计划 §5.3 的 11 条，写成不读代码也能照做的步骤。第 11 条来自决定 U5；2b 是可选的 Hands 一条。
- **怎么用：** 每条只判「通过 / 不通过」。不通过就写一句现象，例如「第 3 轮改错了文件」。
- **记录：** 填在最后的记录表里。只写判定和一句现象，不贴对话内容、路径或截图。
- **用的东西：** 一律是测试材料，不碰你自己的真实文件。
- **模型：** 第 4 条要 Claude 和 DeepSeek 两个模型；第 7 条必须用 Claude；其余各条至少用一个，两个都过更好。记下用的是哪个。
- **哪一版能验：** v0.1.62 能先验第 1、4、6、9 条；其余要等 v0.1.63。还不能验的，记「本版不验」。
- **「需要你核对」在界面上的原话：** 「基本做完了，但有一步改动文件或设置的操作没干净完成——请看一眼结果。」下文说「没有这句」就是指它。

## 开始之前

**升级之前，在 0.1.61 上做（同一天）：**

1. 让它在终端里跑一次 `osascript -e 'display notification "测试"'`，卡上选「总是」。第 9 条要用。
2. 第 10a 条的问题问一次（见下），记下从发出到答完的秒数，中途不插话。

**升级之后：**

3. 打开 Arslan 的终端（让它能跑命令）：第 1、6、9 条要用。
4. Claude 和 DeepSeek 两个模型都配好：第 4、7 条要用。
5. iPhone 已和这台 Mac 配对：第 7、10b 条要用。
6. 工具最多的那个 MCP 服务器已连上：第 4 条要用。0.1.61 因为报 400 关掉过它的，记得重新打开。
7. 第 2 条的材料：在「下载」文件夹里新建「验收用下载」，放 10 个文件名里带日期的测试 PDF（比如 `2026-08-03 收据.pdf`）。
8. 第 5 条的材料：让 Arslan 生成 `test-1000.txt`（每行写「第 N 行」），再自己拷一份 `test-1000-原样.txt` 备用。
9. 第 6 条的材料：在「桌面」新建文件夹「验收用删除」，放 3 个随便的小文本文件。这个文件夹**不在** Arslan 的工作文件夹里，也**不要**加进「允许的文件夹」；整个验收过程**不要**打开「完全访问」。

## 11 条

**1. 跑一条一两分钟的命令（F1、F2；v0.1.62）**
- 步骤：对 Arslan 说「在终端里运行 `sleep 75 && echo 完成`，告诉我结果」。
- 通过：它等命令跑完，回答里有「完成」；没有出现「需要你核对」那句；点开这一步看，错误文字里没有 `tool 'run_command' timed out`。

**2. 一次整理完（K4；v0.1.63）**
- 步骤：说「把下载文件夹里『验收用下载』中的 PDF 按月份整理到 Arslan 文件夹」。
- 通过：一次做完，没让你转后台；10 个文件一个不少（到 Arslan 文件夹里数一数）。另外记一个数：一共出了几张卡。

**2b.（可选）聊天里在一个 Mac App 里做 5 步以上（H3；H3 合并前本版不验）**
- 步骤：说「在备忘录里新建一条笔记，标题『验收』，写三行字，再把第二行加粗」。
- 通过：它在聊天里做完，没有因为「做了 5 次」被要求转后台。

**3. 三轮追问（K2；v0.1.63）**
- 步骤：连着三条：「写一份关于某个话题的三节报告，存成文件」→「把第二节改短」→「再加一个表格」。每一轮之后，把那个文件拷一份（`报告-1.md`、`报告-2.md`）。
- 通过：在终端里 `diff 报告-1.md 报告-2.md`，只有第二节变了；`diff 报告-2.md 报告.md`，只多了表格。

**4. 工具很多的 MCP 服务器不拖垮对话（F3；v0.1.62）**
- 步骤：连着那个工具最多的服务器，用 Claude 和 DeepSeek 各问一句普通的话，比如「今天适合做什么」。
- 通过：两个模型都正常回答；「活动」页里没有失败的运行。

**5. 改大文件里的一处（K5、K6；v0.1.63）**
- 步骤：说「把 test-1000.txt 第 500 行改成『这一行改过了』」。
- 通过：在终端里 `diff test-1000-原样.txt test-1000.txt`，只有第 500 行不同；点开它的步骤看，用的是「编辑」，不是把整份文件重新写一遍。

**6. 拒了以后换个办法（F2；v0.1.62）**
- 步骤：说「删掉桌面『验收用删除』里的 3 个文件」。出删除卡时点「不」，备注写「改成移到废纸篓」。
- 通过：它把文件移到了废纸篓（打开废纸篓看得到）；没有出现「需要你核对」那句。

**7. 回答边生成边出现（K8；v0.1.63；必须用 Claude）**
- 步骤：用 Claude 问一个不需要工具的问题，比如「用三段话介绍一下长城」；再在 iPhone 上问一次。
- 通过：字是一段一段出来的，不是等很久后一下子全出来；iPhone 上也一样。

**8. 撤销本轮的文件改动（S3；v0.1.63）**
- 步骤：先拷一份测试文件（`撤销前.txt`）；让它在原文件末尾加一句话；然后点「撤销本轮文件改动」。
- 通过：在终端里 `diff 撤销前.txt 测试文件`，没有任何不同。

**9. 终端里的 AppleScript 只给「这一次」（F4a；v0.1.62）**
- 步骤：说「在终端里用 osascript 弹一条通知：测试」。再试一次，写成 `/usr/bin/osascript` 的。
- 通过：两次都出卡；卡上只有「这一次」，没有「本对话」和「总是」。升级前选过的「总是」不再算数，照样出卡。

**10a. 读 3 个网页更快（K9；v0.1.63）**
- 步骤：问「比较这 3 个网页上的天气：https://wttr.in/Shanghai?format=3 、https://wttr.in/Beijing?format=3 、https://wttr.in/Shenzhen?format=3」。中途不插话，记下从发出到答完的秒数。
- 通过：比升级前同一天记的秒数少 40% 以上。

**10b. 中途从 iPhone 插话（K9；v0.1.63）**
- 步骤：再问一次 10a 的问题；它开始读网页时，从 iPhone 插一句「只要气温，别的不用」。
- 通过：iPhone 上不再停在「Queued behind the current turn」；它下一步就照做，回答里只有气温。

**11. 回答一出现就能接着问（K2、决定 U5；v0.1.63）**
- 步骤：连着聊 5 轮，每次回答一出现，马上发下一条。
- 通过：每一条都立刻开始处理；聊天里不出现「Arslan 做完当前这条回复后马上读这条」。
