# 体感验收：11 条（每次发版前，你亲手过一遍）

- **是什么：** 总计划 §5.3 的 11 条，写成不读代码也能照做的步骤。第 11 条来自决定 U5。
- **怎么用：** 每条只判「通过 / 不通过」。不通过就写一句现象，例如「第 3 轮改错了文件」。
- **记录：** 填在最后的记录表里。只写判定和一句现象，不贴对话内容、路径或截图。
- **用的东西：** 一律是测试材料，不碰你自己的真实文件。
- **模型：** 第 7 条必须用 Claude；其余各条，两个模型（Claude 和 DeepSeek）各过一遍更好，至少过一个，记下用的是哪个。
- **哪一版能验：** v0.1.62 能先验第 1、4、6、9 条；其余要等 v0.1.63。还不能验的，记「本版不验」。

## 开始之前（一次）

1. 打开 Arslan 的终端（让它能跑命令）：第 1、6、9 条要用。
2. Claude 和 DeepSeek 两个模型都配好：第 4、7 条要用。
3. iPhone 已和这台 Mac 配对：第 7、10 条要用。
4. 工具最多的那个 MCP 服务器已连上：第 4 条要用。
5. 第 10 条要一个 0.1.61 上的用时：升级之前，先在 0.1.61 上把第 10 条的问题问一次，记下秒数。
6. 第 2 条的材料：在「下载」文件夹里新建「验收用下载」，放 10 个文件名里带日期的测试 PDF（比如从任意网页「打印 → 存为 PDF」十次，文件名改成 `2026-08-03 收据.pdf` 这样）。
7. 第 5 条的材料：让 Arslan 帮你生成一个 1,000 行的测试文本（「在 Arslan 文件夹里生成 test-1000.txt，每行写『第 N 行』」），存好备用。

## 11 条

**1. 跑一条一两分钟的命令（F1、F2；v0.1.62）**
- 步骤：对 Arslan 说「在终端里运行 `sleep 75 && echo 完成`，告诉我结果」。
- 通过：它等命令跑完，回答里有「完成」；没有出现「需要你核对」，也没有「timed out」。

**2. 一次整理完（K4；v0.1.63）**
- 步骤：说「把下载文件夹里『验收用下载』中的 PDF 按月份整理到 Arslan 文件夹」。
- 通过：一次做完，没让你转后台；10 个文件一个不少（到 Arslan 文件夹里数一数）。
- 另外记一个数：一共出了几张卡（看 S2a、S4b 之后少了没有）。

**3. 三轮追问（K2；v0.1.63）**
- 步骤：连着三条：「写一份关于某个话题的三节报告，存成文件」→「把第二节改短」→「再加一个表格」。
- 通过：第 2、3 轮改的是同一个文件、同一节；其他节一个字不变（打开文件看）。

**4. 工具很多的 MCP 服务器不拖垮对话（F3；v0.1.62）**
- 步骤：连着那个工具最多的服务器，用 Claude 和 DeepSeek 各问一句普通的话，比如「今天适合做什么」。
- 通过：两个模型都正常回答；「活动」页里没有失败的运行。

**5. 改大文件里的一处（K5、K6；v0.1.63）**
- 步骤：说「把 test-1000.txt 第 500 行改成『这一行改过了』」。
- 通过：它分段读、只改那一行；用「比较」工具（或让 Arslan 给你看前后对比）看，别的行逐字不变。

**6. 拒了以后换个办法（F2；v0.1.62）**
- 步骤：在 Arslan 文件夹里放 3 个没用的测试文件，说「删掉这 3 个文件」。出删除卡时点「不」，备注写「改成移到废纸篓」。
- 通过：它把文件移到了废纸篓（打开废纸篓看得到）；没有出现「需要你核对」。

**7. 回答边生成边出现（K8；v0.1.63；必须用 Claude）**
- 步骤：用 Claude 问一个不需要工具的问题，比如「用三段话介绍一下长城」；再在 iPhone 上问一次。
- 通过：字是一段一段出来的，不是等很久后一下子全出来；iPhone 上也一样。

**8. 撤销本轮的文件改动（S3；v0.1.63）**
- 步骤：让它在一个测试文件末尾加一句话；然后点「撤销本轮文件改动」。
- 通过：文件回到改之前，逐字一样。

**9. 终端里的 AppleScript 只给「这一次」（F4a；v0.1.62）**
- 步骤：说「在终端里用 osascript 弹一条通知：测试」。再试一次写成 `/usr/bin/osascript` 的。
- 通过：两次都出卡；卡上只有「这一次」，没有「本对话」和「总是」；以前点过「总是」的，也照样出卡。

**10. 读 3 个网页更快，中途插话照做（K9；v0.1.63）**
- 步骤：问一个要读 3 个网页的问题（每次用同一个问题，比如比较 3 个城市今天的天气）。记下从发出到答完的秒数。做的过程中，从 iPhone 插一句「只要气温，别的不用」。
- 通过：用时比 0.1.61 那次少 40% 以上（同一时段、两版各跑一次再比）；插的那句话，它下一步就照做。

**11. 回答一出现就能接着问（K2、决定 U5；v0.1.63）**
- 步骤：连着聊 5 轮，每次回答一出现，马上发下一条。
- 通过：每一条都立刻开始处理，不出现「排队」，也不用等它在后台整理完。
