# U10 重跑结果和新基线（A 方案），2026-10-20

U10 定的四件事里 ①②的数字，以及之后 K 线对比要用的新基线。决定和原因见总计划的 U10 和 E25。

## 设置（A 方案）

| 项 | 值 |
|---|---|
| Arslan 怎么起 | `BENCH_SANDBOX=none`：不套 bench 的外层沙箱，Arslan 自己的命令沙箱和产物检查照常工作。`BENCH_FRESH_INSTANCE=1`：每格一个全新实例，跑完就关（#228） |
| 还在的保护 | `env -i`、bench 自己的 HOME、假 key（真 key 只在计量代理里）、Arslan 自己的命令沙箱（结果里是 `sandbox: workspace`） |
| Hermes、Claude Code | 照旧套外层沙箱。Claude Code 的临时目录挪进 bench 根目录（#227） |
| 判分 | judge v2。T1 按这一跑开始的日子算；06:00 前开始的，「明早」两种读法都算对（#229） |
| 模型 | DeepSeek：`deepseek-v4-pro`；Claude：`claude-sonnet-5` |
