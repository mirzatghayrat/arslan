## 目标

在已经发布的 v0.1.62 上，把 M1 升级后的全套题目跑一遍 Pass^3，得到一张基线表：每道题 × 每个参赛者 × 两个模型。之后每个 K 线 PR 都拿它比。

## 谁做什么

| 步骤 | 谁 |
|---|---|
| 写运行清单（下文）、核对环境 | ⓪Plan |
| 装好 Claude Code，在自己的终端里给计量代理设 key | **用户**。key 只放在代理进程的环境变量里。任何会话都不碰 key，也不把 key 写进文件 |
| 启动代理和测试实例，跑 runner | 用户，或用户在场时由 ⓪Plan 代为操作；花钱的那一步由用户按回车 |
| 把 `report.py` 的汇总整理成表，提交本 PR | ⓪Plan |

## 花费（粗估，未实测）

- **D5 的口径：** 整轮约 **$25–50**。
- **算法：** 约 12 题 × 3 次。
  - Claude 模型上跑 Arslan 和 Claude Code，按每次约 $0.3 计；
  - DeepSeek 上跑 Arslan 和 Hermes，按 10-02 那轮每次 $0.03–0.17 计。
- **上限：** 代理的总上限 `BENCH_CAP_USD` 和单次上限 `BENCH_RUN_CAP_USD`，在开跑前由用户设好（`scripts/kernel_bench/meter.py:22-23`）。

## 怎么做（要点）：运行清单

1. **核对测试实例是 v0.1.62。** 记下版本号和 sha。测试实例的 `HOME` 和数据目录都放在 bench 目录下，不用用户的真实数据。
   - **从空的数据目录起实例，跑完就关**（更正 E18）。参考轮 R0 里，实例闲着约 9 分钟后自己调用模型，还把之前作废那轮留下的任务续跑了 3 步。这些花费不算进任何一次，却会用掉代理的额度。
   - runner 读用量前，会等这次跑的标签安静 10 秒（M1a），把每轮结束后那一两次小调用（记忆、学习）算进去。
   - 代理用含 gzip 修复的 meter 启动（M1a），否则 Hermes 每次都秒失败。
2. **固定这些设置**，写进结果文档：
   - 模型版本和推理档位；
   - Claude Code 版本、Hermes 版本；
   - 日期。
3. **开两个计量代理：** 一个指向 DeepSeek，一个指向 Anthropic。
4. **跑四组：**

   | 参赛者 | 模型 | 题目 |
   |---|---|---|
   | Arslan | DeepSeek | 全套 |
   | Hermes | DeepSeek | 全套 |
   | Arslan | Claude | 全套 |
   | Claude Code | Claude | 除 Hands 题以外 |

   - 每组 `--repeats 3`，参赛者交替着跑。
   - 做不到的题记成「不支持」，比如 Claude Code 不能操作 Mac App，见 M1 卡。
5. **出汇总：** `python -m scripts.kernel_bench.report`，按（题, 参赛者, 模型）汇总。

## 改哪些文件

只新增一个结果文档：`docs/plans/0162/M1B-baseline-results.md`。只放数字：

- 每题 × 参赛者 × 模型的 Pass^3、通过次数 / 3、平均花费、平均模型用时、平均调用次数；
- 不支持的题标「—」。
- 第 2 步记下的设置。
- 和 10-02 那轮的差别（新题和判分变化），一两句话。

## 不许碰（写进文档的东西）

- 回复内容、题面里的本机路径、`results.jsonl` 的原始行、运行目录的路径。
- key、账号，以及代理日志里除了计数以外的任何东西。
- 产品代码和 `scripts/kernel_bench/`：要改先回到 M1。

## 验收

- 表里每个格子都有数，或者标了「—」并写明原因。
- 写明这轮总共花了多少钱，以代理记的为准。
- 用户看过表、点头。
- §5.1 的建议门槛值（「不退步」「对 Hermes 不低」「和 Claude Code 的差距缩小一半」「新题 3/3」）用这张表重新核一遍。门槛要调，由 ⓪Plan 写进总计划，由用户拍板。

## 量级

文档约 40–80 行。跑一轮约半天（未实测）。

## 风险与回退

- **噪声：** 单个用户、一台机器跑一轮，误差不小（领先路线 §6：差距小于约 3 分算噪声）。门槛判定要看 Pass^3，不看单次。
- **花费超出粗估：** 代理到上限就停，已经跑完的部分照样能出表。在文档里标「未跑完」。
- **回退：** 结果文档可以重跑覆盖，旧版本留在 git 历史里。
